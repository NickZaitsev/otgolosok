# Редактура рассказов у «Текстильщиков» и в Люблине

Из двенадцати предложенных для прогулки остановок опубликованные рассказы были у пяти. Четыре рассказа исправлены, рассказ о парке имени Шкулёва оставлен: он уже содержит 105 слов и не включает справочный адрес. У семи остальных остановок озвучиваемого текста пока нет.

В [changes.json](changes.json) сохранены исходные редакции, идентификаторы, карточные адреса, координаты, прежние MP3 и новые тексты с фактами и источниками. После удаления почтовых фраз исправленные рассказы содержат 103–128 слов. Адреса и координаты карточек не менялись.

При сверке источников уточнён автор проекта дворца: городской акт относит его к Ивану Еготову; текст больше не приписывает дворец одновременно Еготову и Казакову. Для дома актёров «1801 год» заменён подтверждённым «начало XIX века». Из рассказа об оранжерее исключены точный 1920 год пожара, обеды и перечень плодов, которые не подтверждаются надёжным источником; пояснено, что западный флигель восстановлен. Основной [акт городской экспертизы](https://www.mos.ru/upload/documents/files/2937/AktGIKEAnsamblpodmoskovnoiysadbiLublino.pdf) и [исследование о Достоевском](https://geno.ru/about/news/2409/) приведены в связях фактов с источниками.

Четыре текста опубликованы одной партией после проверки исходных редакций. Резервный снимок исходных строк: `/data/ops-backups/tekstilshchiki-address-cleanup-2026-10-08/before.json` на сервере генератора. Старые файлы оставались доступны во время подготовки новой озвучки. Эти обычные карточки не входят в опубликованную промопрогулку; для будущей прогулки её новые записи должны соответствовать правилу ElevenLabs v4 и голоса «Отголосок2».

Проверки редакции и публичных карточек:

```sh
node --test content/tekstilshchiki-address-cleanup-2026-10-08/verify.test.mjs
node content/tekstilshchiki-address-cleanup-2026-10-08/verify-production.mjs
pnpm check
```

Итоги публикации и сверки MP3 находятся в `publication-receipt.json` и `verification.json` после завершения записей.
