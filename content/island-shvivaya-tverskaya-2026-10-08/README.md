## Озвучка и сохранность

По прямому указанию пользователя «все озвучивай через Elevenlabs v4» готовые v3 для этой очереди не использованы. Созданы 43 отдельные редакции заданий: 42 новых синтеза и одна повторно использованная неизменённая запись v4 о Библиотеке иностранной литературы. У Смирнова прежний v4 не подходит после изменения концовки, поэтому его новая редакция озвучена заново. Суммы длительности не увеличивались паузами, повторением или замедлением.

[Квитанция выполнения](execution-receipt.json) фиксирует 43 задания и три ссылки. По каждой записи проверены `provider: elevenlabs`, `model: eleven_v4`, голос «Отголосок2» и профиль исходного задания; совпали SHA-256 исходного и подготовленного для озвучки текста. Голос основного аккаунта подтверждён API до синтеза; перед завершением повторно проверены [все три аккаунта и их копии «Отголосок2»](voice-accounts-verification.json). Все MP3 скачаны по публичному HTTPS, проверены хеш, размер и длительность через ffprobe; полная слуховая редактура не выполнялась.

[Контроль сохранности](preservation-verification.json) подтвердил неизменность 43 исходных карточек с их прежним аудио, 25 публичных прогулок, двух ранее созданных общих ссылок серии и 6292 OSM-псевдонимов. Импорт отдельных рассказов был транзакционным, с проверкой исходных текстов и аудио; устойчивые ключи заданий и прогулок защищают повтор запуска. Перед серверными изменениями сохранён целевой JSON исходных записей в закрытом каталоге операции, без очередного полного копирования SQLite.

## География и пересечение

Все 43 центра, триггеры, вершины и выборки с шагом 10 м по трём пешеходным линиям находятся внутри внутреннего контура Садового кольца. Подходы к конкретным выходам метро и отклонения триггеров от линии проверены по OSM и пешеходному Valhalla. Полевая доступность не проверялась; `fieldChecked:false` сохранён.

Между этими тремя прогулками **0% общих физических объектов**. Максимум с 27 прежними прогулками — 25%; с остальными вариантами общего плана — 7,69% у Тверской и R06 из-за общего зала Чайковского. Формула: общие канонические физические объекты / меньшее число уникальных физических остановок. Метро, новая редакция и смена голоса не добавляют точки.

## Проверки

[Проверка контрактов](contracts-verification.json): все 43 текста прошли `hasValidStoryText`, три документа — `validateWalkDocument`, три представления — `validateWalkView`. В пакетах маршрутов сохранены матрицы пересечений, геометрия, происхождение MP3 и проверка публичного API с точным совпадением документа, рассказов и хешей звука.

Мобильная проверка Chrome 390 × 844 прошла все 43 остановки: чтение каждого текста, воспроизведение правильного MP3 с ростом позиции, пауза, следующий рассказ и переход к финишному метро. Ошибок JavaScript и HTTP для аудио нет. Скриншоты и MP3 находятся в игнорируемом локальном каталоге операции; полевая и полная слуховая проверки отсутствуют.

Полный `pnpm check` прошёл: lint, TypeScript, 1984 frontend-теста, 1054 backend-теста, Ruff, Pyright, 26 Python-тестов и 78 подтестов, production-сборка. У ESLint 127 существующих предупреждений, ошибок нет. [Итоговая проверка](verification.json) содержит фактические результаты и хеши файлов, нормализованных к LF.
