# Карта короткой прогулки

Исправлена 7 сентября 2026 года. Прежняя произвольная SVG-кривая реки,
условный пунктир и фиктивные остановки удалены. Новый рисунок выводится
из координат берегов, зданий и улиц OpenStreetMap; пешеходный путь записан
в данных прогулки. Масштаб одинаков по обеим осям, север сверху.

## Данные

- Снимок: `public/data/maps/paveletskaya.json`, WGS84 (долгота, широта),
  идентификаторы исходных объектов, дата получения и URL запросов.
- Получен ограниченный [фрагмент OSM API](https://api.openstreetmap.org/api/0.6/map?bbox=37.633,55.718,37.667,55.737).
  Для водных мультиполигонов дополнительно получены полные relations
  [222973](https://www.openstreetmap.org/relation/222973),
  [1451181](https://www.openstreetmap.org/relation/1451181),
  [1451187](https://www.openstreetmap.org/relation/1451187).
  Внешние и внутренние кольца собраны по совпадающим ID узлов; незамкнутое
  кольцо считается ошибкой. Отрисовка использует `fill-rule: evenodd`.
- Выбраны здания, зелёные участки, вода, дороги, наземные железнодорожные пути
  и мосты. Координаты сохранены из источника; оформление авторское.
- У снимка более широкий охват, чем у текущей карты короткой прогулки.
  Для отображения отбираются объекты, пересекающие её границы.
- Данные доступны по `/data/maps/paveletskaya.json`; лицензия
  [ODbL, © OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
  Атрибуция видна под картой и записана в метаданных SVG.

## Сборка

`node scripts/build-map.mjs` читает снимок и маршрут, применяет Web Mercator
с равным масштабом осей и создаёт `public/data/maps/paveletskaya.svg`.
Скрипт входит в `pnpm build`; сетевых запросов при сборке нет.
Точки частей и линия пути берутся из `route.walk`, а не из CSS-процентов.
Линейка 200 м учитывает широту центра карты. Подписи привязаны к координатам
мест и немного сдвинуты для читаемости.

SVG выводится локальным изображением с текстовым описанием. Карточка под ним
не перекрывает географию. При запуске приложения внешние карты и API не
запрашиваются; ссылка «Открыть карту» открывает OSM по явному действию.
Снимок и SVG попадают в существующий офлайн-пакет `data/`.

## Ограничения

Это карта конкретной прогулки, без панорамирования и поиска маршрута в браузере.
Данные отражают снимок OSM, не оперативные перекрытия или режимы проходных.
Картографическая проверка не заменяет отложенную полевую проверку.
Направления, входы и точки для осмотра не помечены как проверенные на месте.
