## Условия продолжения

1. После восстановления SSH перечитать все текущие публичные прогулки, OSM-псевдонимы, исходные карточки и наличие подготовленных job. Сверить их с `expectedStory` и `expectedAudio`: новые материалы не дают права перезаписывать изменённые другим процессом записи.
2. Создать отдельные адресные задания по стабильным `jobId` из пакетов, с повторным использованием уже совпадающих заданий. `placeId` обозначает физический объект; собственный `job` не делает его новой точкой. Не менять общие карточки и документы старых прогулок.
3. Новые записи: `provider: elevenlabs`, `model: eleven_v4`, голос «Отголосок2», `voiceId: 9ivxhQ6xIsHd6R3Xc635`. Старые F5 из исходных карточек не подходят для новой промопрогулки; их доступность сохраняется. Готовые ElevenLabs v3 допустимы для переиспользования только при совпадении текста, голоса и проверенных метаданных.
4. Сначала записать пилот из нескольких разных остановок, проверить произношение и реальный темп. Затем завершить синтез и измерить каждый MP3 через ffprobe. Порог каждой прогулки: **не менее 900 секунд звука**, без добавочной тишины или замедления. Число слов само по себе этот порог не подтверждает.
5. Проверить соответствие каждого MP3 текущему тексту, фактические провайдер/модель/голос и доступность файла. Если сумма меньше 900 секунд, дополнить конкретные рассказы проверенным материалом и записать изменённые версии.
6. Создать общие предпросмотры, проверить весь порядок остановок, текст, воспроизведение и подходы к метро в мобильном интерфейсе. Обновить матрицу пересечений непосредственно перед выпуском. Публикация в общем каталоге в этом этапе не выполнялась.

## Проверки

Документы обеих прогулок прошли штатный `validateWalkDocument`; собранные представления с `text_ready` и `audio:null` прошли `validateWalkView`. Все 25 текстов прошли `hasValidStoryText`, проверку объёма, абзацев и связей фактов с источниками. [Результаты подготовки](verification.json) фиксируют хеши файлов и отдельно отмечают незавершённые серверные, звуковые и браузерные проверки.

Пересечения рассчитаны по снимку 25 публичных одобренных прогулок и 6 292 OSM-псевдонимов от `2026-10-07T16:20:44.492Z`: общие канонические физические объекты / меньшее число уникальных физических объектов. Для остановок старых прогулок без ID также проверены координаты. Оба новых набора имеют 0% с каждым старым маршрутом и с каждым из остальных 12 вариантов общего плана.
