# Замена F5 в 25 промопрогулках

По уточнению пользователя от 7 октября 2026 года готовые записи ElevenLabs v3 сохраняются. Новые записи и замены F5 выполняются через ElevenLabs v4 голосом «Отголосок2». Правило внесено в `AGENTS.md`.

[Проверка production](verification.json) охватывает 25 опубликованных прогулок аккаунта `promo-walks`, 251 остановку и 205 уникальных записей. Заменены 50 записей F5, сохранены без изменения 103 записи v3 и 52 прежние записи v4. Тексты, документы прогулок и общие ссылки сохранены. Замены включают храм Николая в Пыжах, дом-музей Островского и «Возрождение».

Каждый новый MP3 скачан с публичного HTTPS, проверены SHA-256, размер и длительность через ffprobe. Публичный API проверен для всех 25 прогулок. Метаданные провайдера, модели и голоса прочитаны из production, а не определены по имени профиля очереди. Временный дополнительный обработчик использовал штатные блокировки и публикацию заданий; приложение и настройки сервера не менялись.

В старых автоматических маршрутах осталось 12 остановок без рассказа и озвучки (`not_requested`); это отдельные отсутствующие материалы, перечисленные в отчёте. Операция заменяет существующие записи F5 и не создаёт истории для этих остановок.

[Поиск превью «Возрождения»](preview-search.json): найдены снимки самого памятника, проверен визуальный кандидат Надежды Лаптевой. Разрешение на повторное использование не подтверждено, фотография на production не опубликована. Проверенные фотографии усадьбы с Wikimedia Commons не изображают памятник и отклонены. Для публикации нужен собственный снимок либо разрешение автора/приобретённая лицензия.

Полный повторный `pnpm check` прошёл: lint, TypeScript, 1798 frontend-тестов, 978 backend-тестов, Ruff, Pyright, 26 Python-тестов и 78 subtests, production-сборка. Первоначальный запуск остановился на незавершённом тесте CSS-палитры из параллельной работы; после исправления этой работы общий прогон выполнен заново без исключений.
