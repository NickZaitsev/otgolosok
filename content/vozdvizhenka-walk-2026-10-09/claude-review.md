# Разбор аудита Claude Code Opus 5.5

Консультация выполнена до платной генерации шестёрки рассказов. Модель подтверждена `modelUsage` ответа, успех — квитанцией. Claude не открывал источники: предположения проверены редакторами по первичным страницам. Аудит включает пять дополнений R05 и отдельно Храм Христа Спасителя из R03; последний не входит в 13 точек Воздвиженки.

| Замечание | Решение до озвучки |
|---|---|
| M1, Булганин и спор с городскими властями | Убрано; оставлено участие в выборе площадки и оформлении по первичному очерку 1935 года. |
| M2, переезд Алексеевского монастыря | Исправлено на Красное село по сайту монастыря и Патриархии. Географически неточная формулировка xxc.ru не повторена. |
| M3, реконструкция Т-3 | Рассказ описывает опубликованный план 2024 года и не утверждает завершение работ. Текущий вид и полевая доступность не подтверждены. |
| M4, Татиана и Пашковы | Уточнена другая усадьба на Моховой; слово «частный» убрано, добавлен проверенный временный Георгиевский храм. |
| M5/M6, дореволюционный календарь | Месяцы 1837, 1847 и 1912 исключены из рассказов; годы сохранены. |
| M7, слабые/лишние источники | Неиспользуемые факты и источники Т-3/Морозова удалены из новых историй; `beforeStory` остаётся исходным снимком. |
| M8, старый v3 | Только неизменённый «Художественный» сохраняет v3; источник записи, модель, голос, квитанция и загрузка проверяются отдельно. Все шесть изменённых текстов получают v4. |
| M9, длительность | Восемь сохранённых MP3 дают 485,808 с. Пять новых текстов содержат 1121 слово; по самому быстрому из этих готовых v4 прогноз 1063,87 с. Выпуск блокируется, пока измеренные MP3 не дают минимум 900 с. Храм не прибавлен к этой сумме. |

Также разделены послепожарное восстановление и освящение Знамения; интерьер Тимирязева явно описан как музейный; мануэлино отнесено к рубежу XV–XVI веков. Деревянный цирк и применение шахт подтверждены первичными материалами. Факты-абзацы трёх текстов первой группы и Храма раздроблены на отдельные утверждения.

Нормализация озвучки выполняется штатным worker; используется уже проверенная в проекте модель `eleven_v4` и голос «Отголосок2». Новая пробная платная запись ради модели не требуется. Полное слуховое и полевое прохождение не заявляются. Маршрут проходит по общедоступным тротуарам и подземным переходам; действующая видимость закрытых объектов остаётся ограничением.

Повторная консультация после исправлений не проводилась. Финальная редакция и ответственность за публикацию — Codex; исходный ответ аудитора сохранён без изменения.
