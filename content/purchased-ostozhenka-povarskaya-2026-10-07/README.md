# Купленные туры: Остоженка и Поварская

Дата проверки: 7 октября 2026 года. Этап: редакционная подготовка двух прогулок из [общего плана](../../docs/agents/plans/2026-10-07-garden-ring-metro-walks.md). Рассказы не импортированы, аудио не создано, прогулки не опубликованы.

Продолжение: [пакет перед озвучкой](../ostozhenka-povarskaya-2026-10-07/README.md) содержит полные редакции всех 25 остановок, проверенные пешеходные линии и отдельный аудит Opus 5.5. Этот документ и черновики ниже сохраняют историю предыдущего этапа. Актуальное состояние озвучки и серверного доступа следует читать в новом пакете.

На выбранных ID оба маршрута имеют 0% общих точек с каждым из 25 опубликованных маршрутов и друг с другом. Их состав и порядок сохранены. Кандидаты ниже не включены в эту цифру. Перед выпуском нужно заново проверить актуальные публичные прогулки, физическую идентичность остановок и доступ с улицы.

Подготовлены два первых рассказа и шесть дополнений: [читаемые тексты](drafts.md), [структурированный пакет](editorial-drafts.json). Добавочный объём — 708 слов для R02 и 420 для R04. Для существующих карточек это именно дополнение к тексту, а не замена рассказа. После объединения удалить повторы и заново записать **полный изменённый рассказ**. Старый MP3 изменённой карточки исключить из суммы: складывать его с новым полным MP3 нельзя.

Количество слов не доказывает хронометраж. При условном темпе 100–140 слов/мин добавления составляют около 5:03–7:05 и 3:00–4:12; по этой условной оценке R02 уже имеет запас, а быстрый край R04 всё ещё ниже 15 минут. Эти расчёты не учитывают сокращения при редактуре и изменение длительности старого текста. Приёмка: сумма окончательных MP3 от 900 секунд, желательно с запасом около минуты; проверка через ffprobe и прослушивание в порядке прогулки. Для R02 подготовлены новые дополнения о рабочих курсах и Тургеневе по городскому акту и сайту музея. Для R04 остаётся исследовать ещё примерно 100–150 содержательных слов о московском периоде Лермонтова или литературной экспозиции Горького; это очередь исследования, а не уже готовые факты. Если после записи звука не хватает, добавить проверенный сюжет, затем измерить снова.

## Что удалось прочитать

- **Поварская:** оглавление 77 глав, полные тексты всех 77 получены через обычный интерфейс IZI. Это чтение текстов, а не прослушивание записей и не независимая проверка каждого утверждения.
- **Остоженка:** после входа пользователя получены полные тексты всех **86 глав**, включая ранее недоступные 39 и 57. Во всех главах отсутствовал блок покупки, текст не был усечён. Предыдущие 84 превью остаются только историей проверки; полный доступ восстановлен, повторная покупка не нужна.
- [Квитанция чтения](reading-receipt.json) содержит длины и хеши полученных текстов без самих платных материалов. Их локальные копии для анализа находятся только в игнорируемом `artifacts/`.

[Сверка 25 остановок R02/R04](route-stop-review.md) показывает соответствующие главы и решения для каждой выбранной точки. [Таблица всех 163 глав](chapter-review.json) содержит 32 привязки к карточкам: 17 по полному тексту Поварской и 15 по полному тексту Остоженки. Ещё шесть глав отнесены к контексту существующего комплекса. Остальные находятся в очереди проверки, относятся к улицам или коммерческим названиям. Отсутствие привязки не доказывает, что точки нет в каталоге. Координаты маркера и ближайшая карточка сами по себе не подтверждают совпадение объектов.

## Покупки и следующий этап

**Новых покупок для подготовки R02/R04 сейчас не требуется.** Пользователь подтвердил обе покупки; повторять их нельзя. По Поварской материала достаточно для редакционного этапа. По Остоженке полный доступ восстановлен; материалы R02 дополнены на его основе, с проверкой новых фактов по независимым источникам.

Дальнейшая покупка из исходного списка — «Новокузнецкая и Татарская», только после адресной сверки её состава для R09. Затем оценить «Воздвиженку» по оставшемуся дефициту R05. Первую очередь R08/R10/R12 можно готовить на существующем материале. Подробная таблица всех 16 предложенных туров остаётся в общем плане.

Порядок продолжения: разрешить адресные/исторические конфликты → объединить и отредактировать рассказы → построить пешеходные линии и триггеры → озвучить → измерить окончательные MP3 → проверить свежую матрицу пересечений и воспроизведение → выпуск. Полевая проверка отмечается отдельно; кабинетное чтение источников её не заменяет.

## Проверка этого этапа

[Аудит Claude Code Opus 5.5](claude-audit.md) относится к исходным черновикам, после него применены сокращения; финальная редакция повторно не аудирована. Модель подтверждена квитанцией CLI. Проверка структуры пакета и исходной матрицы сохранена в `verification.json`. Полный `pnpm check` прошёл после редакционного этапа; это проверка проекта, не готовности новых прогулок к выпуску.

## После восстановления доступа

Получены все 86 полных глав Остоженки; вместе с Поварской доступны 163 текста. Добавления о рабочих курсах и Тургеневе написаны самостоятельно по городскому акту и музейному описанию; платные абзацы в пакет не переносились. У Тургенева сохранены музейные даты проживания матери 1840–1850 вместо 1839–1851 в аудиогиде. Глава Цветковской галереи неверно описывает судьбу дара: источник ГлавУпДК подтверждает передачу Москве в 1909 году, действующий рассказ уже содержит эту версию. Советы тура войти в открытые усадебные дворы не используются без проверки публичного доступа.

Новый городской акт по рабочим курсам называет здание 1908 года, архитектора Башкирова, занятия хора и художественной студии, выставки и лазарет. Для надписи на доске сохраняется её собственный диапазон 1908–1922; охранное наименование здания содержит 1908–1921. Эти разные источники не заменяются друг другом.

Новые дополнения не входили в сохранённый аудит Claude. Его квитанция и замечания остаются историей предыдущей редакции; новый аудит не заявляется.
