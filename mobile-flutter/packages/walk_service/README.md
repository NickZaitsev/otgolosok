# walk_service

Локальный плагин Отголоска: служба переднего плана Android, которая держит прогулку при выключенном экране (геолокация, Media3-плеер, карточка на экране блокировки и Live Update на Android 16).

Контракт с Dart описан в `pigeons/walk_service_api.dart`. После его изменения:

```bash
dart run pigeon --input pigeons/walk_service_api.dart
```

Сгенерированные файлы коммитятся. Подробности — `docs/agents/mobile-flutter.md`.
