## Доступ

У тебя есть терминал с полным доступом: выполняй команды сам, начиная с `pwd && git status --short`.
Отчёт без выполненных команд не принимается.

Сервер — `ssh "$VPS"`, где `VPS` берётся из gitignored `.env.ops` этого репозитория: начинай каждую
команду с `VPS=$(sed -n 's/^VPS=//p' .env.ops) &&` (окружение Codex эту переменную не наследует).
Адрес никуда не записывай и не выводи.
Содержимое `.env`, токены и ключи не печатай. Многострочные команды передавай через stdin
(`ssh "$VPS" bash -s <<'EOF' ... EOF`), а не через вложенные кавычки.

## Что проверить

1. Журнал тика промо за 24 часа:
   `journalctl -q -t otgolosok-promo --since "-24h" | grep -v -E "Container .* (Creating|Created)"`.
   Ищи `"level":"error"`, `"level":"warn"`, `retry:`, `failed:`, коды `TELEGRAM_`, `SUBTITLE_`,
   `PROMO_`, `ELEVENLABS`. Проверь и отсутствие ожидаемых событий: вечером (20:00–24:00 МСК)
   `proposed:` или «очередь промо пуста», ночью (03:00–06:00) `built:`, утром после 10:00 `preview:`,
   вечером в слот `published:`.
2. Журнал аналитики: `journalctl -q -t otgolosok-youtube-analytics --since "-24h"`.
3. Состояние очередей, только чтение (`sqlite3` по URI `file:...?mode=ro`, либо `python3`):
   - Shorts: `/srv/sites/otgolosok-content/data/state/shorts.sqlite`, таблицы `promo_items`
     (status, slot_at, error, attempts, updated_at) и `settings` (`notice:*`, `story-options:*`);
   - сайт: `/srv/sites/otgolosok.softmg.tech/generator-data/auth.sqlite`, таблица `promo_queue`.
   Сверь: есть ли выпуск на сегодняшний слот (пн–чт 20:30, пт–вс 21:30 МСК); сколько `queued`
   осталось на сайте; нет ли `failed` за сутки и `building` дольше суток; совпадают ли статусы
   и слоты в обеих базах.
4. Здоровье: `docker ps` (контейнеры генератора и valhalla запущены), `df -h /` (свободно больше 3 ГБ),
   `du -sh /srv/sites/otgolosok.softmg.tech/generator-data/ops-backups`.
5. Ревизия Shorts: `cat /srv/sites/otgolosok-content/app/REVISION` против `git -C ../otgolosok-shorts
   rev-parse --short origin/main` (сначала `git fetch`).

## Что делать

- Временную ошибку (сеть, 5xx, 429, таймаут), которую тик повторит сам, не трогай, только отметь.
- Выпуск в `failed`: найди причину по журналу и коду ../otgolosok-shorts. Возвращать выпуск в очередь
  или запускать `promo:build` можно только под `flock /tmp/otgolosok-promo.lock` и только если это
  не создаёт новую платную озвучку или генерацию. Платные повторы, переозвучку и перенос
  опубликованных выпусков не запускай: опиши их и задай вопрос владельцу.
- Дефект кода исправляй в ../otgolosok-shorts, начиная с теста, воспроизводящего сбой; прогони
  `pnpm check` и закоммить по правилам репозитория. Работай в текущей ветке `main` после
  `git pull --ff-only`, без `git stash`. Выкладывай только если ревизия прода совпадает
  с `origin/main`, только штатным `scripts/deploy.sh` и только в фоне; после выкладки — `git push`.
  Если ревизии расходятся, не выкладывай, а сообщи.
- Пустая очередь на ближайшие два слота: выпуски сам не придумывай, сообщи владельцу.
- Озвучка — только ElevenLabs `eleven_v4`, голос «Отголосок2».
- Не удаляй данные, не меняй `.env`, не запускай ничего, что публикует наружу, без поручения.
