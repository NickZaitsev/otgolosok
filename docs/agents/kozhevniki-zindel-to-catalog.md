# Прогулка «От Кожевников к Цинделю» на местах каталога

6 октября 2026 года встроенная прогулка `msk-kozhevniki-zindel-short` перенесена на общую схему ([план](plans/2026-10-06-kozhevniki-zindel-to-catalog.md), [пакет](../../content/kozhevniki-zindel-2026-10-06/README.md)). Её четыре рассказа стали местами каталога и видны на карте «Рядом»; прогулка опубликована от `promo-walks`: https://otgolosok.online/walk?share=901d1133-44a2-4724-a856-2fe8d6c86a44 .

## Что сделано на production

- Импорт одной транзакцией: три новых места (`osm:way:192584381`, `osm:way:56460859`, `osm:way:48346310`) и новая редакторская редакция у существующего `osm:node:2330688388`. Перед записью сохранена резервная копия затронутых строк в `/data/ops-backups/kozhevniki-zindel-2026-10-06/backup-before.json` контейнера генератора; повторный импорт пропустил все четыре записи.
- Прогулка создана с ключом идемпотентности `kozhevniki-zindel-20261006`, перед этим база аккаунтов сохранена через `VACUUM INTO` в тот же каталог.
- Озвучка ElevenLabs, голос «Отголосок2», модель `eleven_v4`: ровно четыре текста, все с первой попытки, 300,9 секунды. Файлы проверены по SHA-256, размеру и ffprobe ([квитанция](../../content/kozhevniki-zindel-2026-10-06/audio-verification.json)).
- В Chrome 390 × 844 проверены четыре метки прогулки и карточки всех четырёх мест на «Рядом» с текстом и плеером; ошибок JavaScript нет.

## Старая ссылка

Сайт собирается статическим экспортом (`output: "export"`), поэтому редиректы `next.config` не работают. В данных маршрута стоит `moved_to_share`; API `/api/story-walks/<id>/view` отвечает для такой прогулки `410 WALK_MOVED` с токеном, а `walk-screen.tsx` заменяет адрес на `/walk?share=…`. Список `/api/story-walks`, топ и «Прогулки рядом» пропускают перенесённые прогулки (`listedCatalogRoutes` в `backend/walk-catalog.mjs`), избранное ведёт на новую ссылку. Админская витрина встроенных прогулок её по-прежнему показывает: тесты этой витрины опираются на реальные данные, а подсистему целиком уберёт [второй план](plans/2026-10-06-retire-builtin-catalog-tour.md).

Пока код не выложен, старая ссылка на production открывает прежнюю встроенную прогулку. Выкладка отложена по решению пользователя: в `main` вместе с этим кодом лежит незавершённая параллельная работа других агентов.

## Наблюдения

- После смены текста у места `getPublishedPlace` продолжает отдавать последнее аудио прежней редакции, пока новая не озвучена. У «Кожевников» несколько минут звучала старая запись F5. Ставить озвучку сразу после импорта.
- У mos.ru сертификат российского удостоверяющего центра; локальный curl его не принимает. Проверку TLS не отключали, факты подтверждали по другим открытым источникам.
- Overpass API отвечал 406; данные OSM взяты из `api.openstreetmap.org/api/0.6/map` по рамке.
- `createWalkPlanner` принимает `minutes` только 30/60/90, а документ — ещё и 15: планировать с бюджетом 30. Крытые участки находятся, если передать `traceUrl` публичного Valhalla.
