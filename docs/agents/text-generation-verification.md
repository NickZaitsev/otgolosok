# Проверка генерации текстов

Дата: 2026-09-18.

Пайплайн принимает ссылки только из метаданных поискового инструмента, безопасно загружает HTML до 1,2 МБ и PDF до 25 МиБ, извлекает точные цитаты и допускает один содержательный источник, включая Википедию. Новые автоматические доказательства различают идентичность, собственный адрес объекта и полезное содержание; без содержательного факта текст не создаётся. Адрес можно произнести только при связи с отдельным адресным доказательством.

Автор возвращает обычный русский текст; JSON используется для извлечения доказательств и решения редактора с одной попыткой исправления формата. Редактор перечисляет проверяемые утверждения, связывает их с фактами и отдельно оценивает содержательность, соответствие предмету и понятность на слух. Короткий подтверждённый результат на 20–100 слов сохраняется как `description-v1` и не отправляется в TTS; понижение профиля применяется и после редакторского исправления. Публичный список источников включает только источники реально использованных фактов.

Локальные тесты покрывают антибот-заглушки, JavaScript-оболочки, отдельный лимит PDF, единственный источник и единственную Википедию, адрес без доказательства, отсутствие содержания за названием и категорией, дубли, короткое описание, полное покрытие утверждений, фактическое отклонение редактором, сохранение последнего кандидата и отсутствие TTS для описания. Старые редакторские доказательства остаются доступны для ручной работы, а незавершённый автоматический checkpoint старой версии повторно проходит извлечение и проверку. Тесты не вызывают платные API и поэтому не доказывают качество живого поиска или историческую достоверность конкретных объектов пилота.

Перед возобновлением массовой партии рекомендуется выполнить ограниченный платный пилот и вручную проверить идентичность, цитаты, естественность речи и качество текста. Это отдельный платный запуск, которого локальная реализация не выполняет. Незавершённые старые checkpoint автоматически инвалидируют доказательства и черновик прежней версии, сохраняя загруженные источники; `restartFrom: "research"` нужен, если требуется также повторить живой поиск. Готовые публикации и ручные правки не изменяются.
