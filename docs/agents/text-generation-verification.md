# Проверка генерации текстов

Дата: 2026-09-18.

Пайплайн принимает ссылки только из метаданных поискового инструмента, безопасно загружает HTML до 1,2 МБ и PDF до 25 МиБ, извлекает точные цитаты и допускает один содержательный источник. Автор возвращает обычный русский текст; JSON используется только для извлечения доказательств и решения редактора с одной попыткой исправления формата. Короткий подтверждённый результат сохраняется как `description-v1` и не отправляется в TTS.

Локальные тесты покрывают антибот-заглушки, JavaScript-оболочки, отдельный лимит PDF, единственный источник, три факта, короткое описание, фактическое отклонение редактором, сохранение причин невалидного черновика и отсутствие TTS для описания. Тесты не вызывают платные API и поэтому не доказывают качество живого поиска или историческую достоверность конкретных объектов пилота.

Перед возобновлением массовой партии нужно выполнить ограниченный платный пилот на объектах из отчёта пользователя и вручную проверить идентичность, цитаты и качество текста. Старые задания после изменения загрузчика следует повторять с `restartFrom: "research"`, чтобы очистить исследовательский checkpoint; готовые публикации и ручные правки при этом не удаляются.
