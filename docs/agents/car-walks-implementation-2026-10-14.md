# Автомобильные прогулки: реализация и проверки

Режим «На машине» хранится как предпочтение для новых черновиков. Сохранённая поездка содержит собственный режим, визиты на парковки и отдельные автомобильные/пешие сегменты. Время 60/120/180 минут включает переезды, пешие петли, пять минут на историю и пять минут на парковку. Пробки не учитываются, автоподбор может вернуть более короткий маршрут.

Автоподбор требует общественную парковку и опубликованную историю. Неизвестный доступ допускается только через явный ручной выбор с предупреждением. Во время переезда и возвращения к машине рассказ остановлен; посещение начинается кнопкой после парковки. Яндекс Карты получают въезд парковки и автомобильный режим.

## Индекс

Команда сборки:

```sh
uv run python scripts/build-osm-parking-index.py artifacts/kazan-osm/moscow-kazan.osm.pbf --output backend/data/osm-parking.sqlite
```

Исходник SHA-256: `4b71f40ead2158dfef09186d4cfe094be97b9823c1f2db4e361e5767cd51c1fc`. Время последней правки включённого объекта: 2026-09-04T03:31:53+00:00. Найдено 3712 парковок, из них 1487 общественных и 2225 с неизвестным доступом; 136 ячеек. Исключены 2036 объектов по доступу, 15253 по типу и 2317 без точки подъезда; 17 въездов взяты из явных объектов, 3695 из подъездных дорог.

Для production собрать индекс в `DATA_DIR/osm-parking.sqlite` (фактический каталог определяется запуском backend) и перезапустить backend. Индекс читается в неизменяемый снимок при старте. SQLite — локальный артефакт, в git не включён. Без индекса API возвращает 503, пешеходный планировщик продолжает работать.

Ограничение: импорт назначает одну найденную точку всем трём ролям въезда, выезда и пешего доступа. Правильное дальнейшее улучшение — извлекать независимые въезды/выезды и пешеходные выходы из дорожного графа; пока доступность подтверждает Valhalla и пользователь проверяет ограничения на месте.

## Проверки

`npm run check` прошёл: ESLint/CSS, оба TypeScript-проекта, Vitest, backend node:test, Ruff/Pyright/Pytest и production-сборка. Остались существующие предупреждения ESLint в локальных операционных скриптах, ошибок нет. Проверены адаптеры/миграция, ручной порядок, общий бюджет, неизвестный доступ, отсутствующий путь, временные ошибки, очередь, deadline, API парковок, отсутствие аудио в дороге и офлайн-сохранение автомобильного контракта.

Playwright: 11 сценариев Chromium прошли, включая поездку с парковкой/возвратом/восстановлением прогресса при ширине 390 и 1280 и прежнюю навигацию при повороте телефона. В dev-логе обнаружена существующая ошибка `/service-status` с `generateStaticParams()` при `output: export`; сценарии и production build проходят. Исправление этого отдельного маршрута требует отдельной задачи.

Реальная проверка локальным Valhalla `http://127.0.0.1:8012/route` и собранным индексом: парковка `osm:way:539698603`, прямой автомобильный участок 3353 м, пешая петля 214 м, обратный автомобильный участок 1954 м. Общее время с посещением/парковкой 23 минуты. Разные прямой и обратный пути рассчитаны независимо, искусственная линия не использовалась.

Продукт не развёрнут на production в рамках этой работы.
