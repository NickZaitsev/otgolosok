# Английский и упрощённый китайский интерфейс

Дата: 7 октября 2026 года. Реализация в текущей ветке `main`; production не обновлялся. Объём согласован с пользователем: интерфейс сейчас, перевод рассказов и озвучка позднее. [План и следующий этап](plans/2026-10-07-ui-localization.md).

## Маршруты и переводы

Русские страницы сохраняют прежние адреса. Английские доступны под `/en`, китайские под `/zh`; обе версии содержат главную, `/walk`, `/history`, `/account`, `/login`. `html lang` — `ru`, `en`, `zh-Hans`. Админка остаётся русской, API, медиа и исходные документы не получают языкового префикса.

Страницы перенесены в две группы root layouts: `src/app/(ru)` и `src/app/[locale]`. Оболочка документа и metadata общие в `src/lib/i18n/root-document.tsx`. Каждый публичный маршрут задаёт собственные canonical/hreflang, приватные страницы закрыты от индексации. Для static export заранее перечисляются `en` и `zh`.

Важно для route handlers: локализованный `manifest.webmanifest/route.ts` содержит собственный `generateStaticParams`. При Next 16.3.4 одного генератора родительского layout недостаточно: export сообщает об отсутствии параметров обработчика. Manifests имеют общий `id: "/"` и scope `/`, но локализованные язык, описание и `start_url`.

`useI18n()` возвращает `locale`, `languageTag`, `t(source, values)` и `path(href)`. Русская исходная строка служит ключом словаря; параметры именованные. Словари разделены по feature-группам. Слияние допускает одинаковые переводы одного ключа, но отклоняет конфликтующие. Проверка AST находит статические UI-строки, отсутствующие в словарях, включая условные сообщения ошибок; отдельная проверка сверяет placeholders.

`localizedPath` изменяет только пять публичных маршрутов, сохраняет query/hash и исключает внешние ссылки, API, admin и assets. Переключение языка заменяет документ, сохраняя эти параметры; активная прогулка или воспроизведение требуют подтверждения. В узкой шапке карты элементы переносятся целиком, не обрезая логотип, переключатель или кнопки; фото сохраняет минимальную высоту доступного элемента управления.

## Граница интерфейса и контента

Рассказы, заголовки мест и прогулок, адреса, факты, цитаты, отзывы, пользовательский ввод и записи сохраняют исходный язык. Русские тексты истории отмечены `lang="ru"`; иностранная карточка объясняет, что текст и звук пока русские. Автоматический заголовок нового черновика тоже сохраняется на русском: язык интерфейса не меняет данные маршрута.

Обычные ссылки и возврат после входа сохраняют UI locale. Для share-ссылок мест используется прежний `/place/<type>/<id>` с `?lang=en|zh`; backend и native converter открывают нужную языковую карту. Русские URLs не меняются, неизвестный `lang` ведёт на RU. Open Graph содержит настоящий русский текст истории.

Известные API/браузерные ошибки переводятся через `toUserMessage(error, fallback, locale)`. В EN/ZH неизвестные сообщения сервера заменяются понятным локализованным fallback; неизвестные данные не попадают в переводчик. Русский контракт этой функции сохранён.

## Офлайн и следующие этапы

Service Worker включает языковые HTML/manifests в precache и нормализует разрешённые aliases. Кеш закрытых API и админки не добавлен. Ручное восстановление `/update.html?lang=en|zh` показывает локализованные действия и возвращает на нужную главную.

Язык UI сейчас не влияет на ключи историй, аудио, прогресса и офлайн-пакетов, поскольку контент общий. При переводе контента необходимо отдельно версионировать его локаль, исходную ревизию, редакторское утверждение и provenance аудио; одной смены UI locale недостаточно. Платная генерация и пригодность ElevenLabs v4/«Отголосок2» для EN/ZH в этой задаче не проверялись.

## Проверки

`pnpm check` прошёл: ESLint, Stylelint, Prettier, оба TypeScript проекта, 128 Vitest-файлов / 1 938 тестов, 980 backend-тестов, Ruff, Pyright, 26 Python-тестов / 78 subtests и production export. ESLint сохраняет 127 ранее существовавших предупреждений, новых ошибок нет. CSP сформирован для 19 страниц, precache содержит 76 файлов.

Production-экспорт прошёл 8 браузерных проверок EN/ZH: исходный русский рассказ, язык документа, навигация/вход, параметры ссылки, отмена и подтверждение смены языка во время прогулки, экраны 320×568, 390×844, 568×320, 1280×844 и переходы без сети. При измерении production-layout тест сначала дожидается контролирующего Service Worker и открывает свежий документ: начальная установка может перезагрузить страницу через существующий механизм безопасного обновления.

Полный Chromium-прогон: 586 успешных сценариев, один ожидаемо пропущенный offline-тест для dev server и четыре падения старого требования «шапка всегда в одну строку» в тесте прогулки. Требование обновлено на отсутствие перекрытия с сохранением одной строки на широких экранах; все шесть размеров этого сценария прошли повторно. В сумме подтверждены все 590 dev-сценариев, offline-сценарий отдельно прошёл на production export. Проверки общей раскладки, видимости меток, доступности кнопок и панелей остались активными.

WebKit не смог запуститься даже в отдельной минимальной пробе: установленный `webkit_mac14_arm64_special-2251` завершается с `Bus error: 10` до открытия страницы. Safari остаётся непроверенным; правильное продолжение — прогон на совместимом WebKit либо реальном iPhone/Safari, а не исключение проверок из репозитория.

Локальный пользовательский dev server уже занимал Next dev lock на порту 3001. Для E2E использовался временный proxy на штатный порт 3217 с передачей WebSocket: некоторые тестовые backend-серверы проверяют Origin именно этого порта. Прямой запуск на 3001 дал ожидаемый CSRF-отказ в тесте счётчика запусков; это не дефект приложения. Временные настройки и proxy находятся за пределами репозитория.
