# Шестой аккаунт ElevenLabs и вывод исчерпанных ключей

12 октября 2026 года в новом локальном аккаунте создана копия голоса «Отголосок2» из того же образца, что использовался для предыдущей копии. API подтвердил имя, категорию `cloned`, русский язык и новый ID `Ap9zcFThybIlczwrI2jU`.

По уточнению владельца первые два ключа исчерпали кредиты. Они удалены из локального `.env` и серверного `.generator.env`; старое одиночное поле `ELEVENLABS_API_KEY` очищено. На сервере новый аккаунт был бы шестым по истории добавления, но после удаления двух старых осталось четыре активных ключа. Их копии голоса идут в порядке `8Hp7MfQf2HGTKtrxXvVj`, `AwgkJqbg2v9ygy3sWXCJ`, `TlRKEpAiY3799BTUYfvL`, `Ap9zcFThybIlczwrI2jU`. Локальный `.env` не содержит серверный аккаунт с ID `AwgkJqbg2v9ygy3sWXCJ`, поэтому локально осталось три ключа. Секреты не записаны в репозиторий.

Основной `ELEVENLABS_VOICE_ID=9ivxhQ6xIsHd6R3Xc635` сохранён как логический ID голоса для уже опубликованных артефактов и профиля очереди. Первый активный ключ теперь сам использует привязку `key:voiceId`; этот путь проверен отдельным тестом, включая передачу следующему ключу при исчерпании кредитов.

Перед изменением серверный `.generator.env` с правами `0600` сохранён в закрытом каталоге `backups/env-elevenlabs-20261012T161942Z/`. Сервис пересоздан под `.deploy.lock`, контейнер стал `healthy` и получил ровно четыре ожидаемых привязки. Бесплатные запросы из контейнера через рабочий прокси подтвердили HTTP 200, имя «Отголосок2» и русский язык для всех четырёх голосов. Публичный `/api/content/map-cells` ответил HTTP 200. Один короткий пробный синтез новым ключом через production-прокси с точной моделью `eleven_v4` и голосом `Ap9zcFThybIlczwrI2jU` вернул HTTP 200 и MP3 размером 23 031 байт; файл не публиковался.
