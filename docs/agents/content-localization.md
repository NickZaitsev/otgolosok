# Переводы содержания и пилот Третьяковки

Интерфейс поддерживает RU/EN/简体中文; содержание выбирается отдельно через `?lang=en|zh` в API карточек и прогулок. Отсутствующий, неутверждённый или устаревший перевод возвращает русский текст с явными `requestedLocale/contentLocale/fallbackReason`. Утверждённый перевод получает только собственное аудио или `null`; русский MP3 к переведённому тексту не подставляется.

## Редакции и импорт

`place_story_translations` и `walk_text_translations` не изменяют русские строки. Перевод привязан к идентификатору и SHA-256 русского источника; изменение источника делает прежний перевод устаревшим. Импорт всех историй и метаданных выполняется одной транзакцией. Повтор актуального импорта идемпотентен; восстановление заменённого текста создаёт новую редакцию для аудита.

Пакет `content/tretyakovka-translations-2026-10-07` снят с публичной редакции 7, общей ссылки `6cacfdd1-defd-4afb-940f-5085356d0315`, содержит 13 остановок. Исходный пакет 2026-10-04 содержит только семь рассказов и недостаточен для текущего пилота. EN/ZH файлы имеют статус `draft`, происхождение машинное; их нельзя представлять как проверенные носителем или автоматически утверждать при импорте.

Перевод документа является проекцией для показа. Изменение пользовательской прогулки должно опираться на `sourceDocument`, когда он присутствует, чтобы иностранные переходы и заголовок не перезаписали русский оригинал. Кеши карточек, офлайн-манифесты и ключи прогресса разделяются по локали; прежние русские ключи сохраняются.

## Подготовка звука

Клиент ElevenLabs передаёт `language_code`, обработка китайского текста учитывает `。！？`, а иностранные тексты обходят русский нормализатор. RU ключи и готовые записи сохраняются; иностранные ключи включают язык. Основание для явного языка: [официальная документация ElevenLabs](https://elevenlabs.io/docs/overview/capabilities/text-to-speech).

Регистрация EN/ZH профилей, привязка `place-translation:<id>` к существующей очереди, отмена задач при смене перевода/источника и пробная платная генерация ещё не реализованы. Это обязательная часть будущего этапа озвучки: нельзя вручную подставлять перевод как `place-text` или генерировать три независимых worker одновременно. Нужны один dispatcher, точные `eleven_v4`, язык и настроенный ID голоса «Отголосок2», проверка исходной и переведённой контрольных сумм, атомарное принятие артефакта и защита от устаревшего lease. Сейчас никаких платных задач не создаётся.

## Редакторские замечания

8 октября редакторская задача закрыта в подготовленном пакете: в русском рассказе о приюте и обеих языковых версиях убрано преждевременное завершение. Топонимы, названия картин, икон и романа сверены по первичным источникам; конкретные решения и пределы доказательств перечислены в [отчёте сверки](../../content/tretyakovka-translations-2026-10-07/editorial-review.md). Для Дербиц сохранена фонетическая форма с русским оригиналом; для картин без найденного китайского каталога выбран редакторский перевод, не заявленный официальным.

Исходный опубликованный снимок сохранён без изменений в `source.published-2026-10-07.json`. Рабочий `source.json` теперь редакционный, с базовым хешем и одной согласованной правкой русского источника. Импорт сверяет архив и актуальную базовую строку; для атомарного применения русской редакции вместе с черновиками переводов нужен `--apply --apply-source-edits --db <путь>`. Повтор полного совпадающего импорта идемпотентен; частичный, заменённый или устаревший результат вызывает конфликт. Без явного флага источник не меняется.

Рабочая база, сайт и MP3 в рамках сверки не менялись. Прежняя русская запись содержит старую фразу; на этапе звука нужна новая запись ElevenLabs v4 голосом «Отголосок2», сохраняя старый MP3 до готовности замены.

Сохранение прежнего русского аудио при новой редакции текста — существующее поведение до готовности замены. Иностранное аудио требует точного совпадения с утверждённым переводом и исходной историей.

## Среда проверки

Локальный WebKit ранее завершался `Bus error 10` ещё до открытия страницы; успешный Chromium не подтверждает Safari. Публичный API общей прогулки поддерживает GET, а HEAD возвращает 404; для снятия сжатых JSON использован `curl --compressed`.

Повторное утверждение русского текста сравнивает SHA-256 всей истории, включая факты и источники. Прежнее сравнение только заголовка и абзацев игнорировало исправления доказательств; четыре теста закрепляют новую исходную редакцию и устаревание переводов при изменении только фактов, источников, даты или адреса.

Проверки этапа: полный `pnpm check` (1965 frontend / 1017 backend, Python, сборка); финальный полный Chromium прогон — 593 успешных и один production-only пропущен; обнаруженные два сбоя исправлены и весь прогон повторён успешно. Статический i18n прогон 11/11 включает смену языковой оболочки без сети из Service Worker. Изолированная SQLite проверяет импорт 26 черновиков и последующее явное утверждение всех 13 историй на двух языках.

Проверка редакционной сверки 8 октября: `pnpm check` прошёл на текущем рабочем дереве (1992 frontend-теста, 1025 backend-тестов, Python и сборка). Отдельно 66 профильных тестов проверяют архивную привязку, одновременное наличие EN/ZH, отказ до открытия базы без явного флага, конфликты источника, атомарность и происхождение аудио. Настоящий CLI дважды применён к временной SQLite с публичными базовыми идентификаторами: русский текст исправлен, созданы ровно 26 черновиков, повтор не создал дубликатов; временная база удалена. Архивный файл побайтно совпадает с исходным `source.json` коммита `746cf1d`.
