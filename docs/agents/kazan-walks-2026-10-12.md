# Казань: прогулки K01 и K02, 12 октября 2026

Выпуск первых двух казанских промопрогулок по [плану](plans/2026-10-12-kazan-center-and-promo-walks.md): 28 новых рассказов, фото и записи ElevenLabs v4, общие ссылки. Квитанции и тексты — [content/kazan-walks-2026-10-12](../../content/kazan-walks-2026-10-12/README.md).

## Наблюдения

- **Темп записей v4.** 28 записей: 3813 слов за 1953 секунды — около 117 слов в минуту, разброс 105–127. Для оценки 15 минут закладывать примерно 1900 слов на прогулку; Codex в аудите считал по 130 словам в минуту и занижал длительность.
- **Очередь ElevenLabs** обрабатывает записи последовательно, примерно по 1,5–2 минуты на каждую; 28 записей шли около 45 минут. Одна получила `TTS_FAILED` и прошла со второй попытки автоматически (`retry_wait`).
- **Фото.** На production `PLACE_IMAGE_SYNC` не задан: фото из Wikidata сами не подтягиваются, нужен редакционный каталог и деплой генератора и статики. P18 в Wikidata бывает непригоден: у памятника Шаляпину там почтовая марка, у Галеевской мечети — снимок здания до реставрации. Контактный лист перед коммитом обязателен.
- **HTTP/2.** production принимает только HTTP/2: `urllib` из Python получает `505 HTTP Version Not Supported`. Скачивать MP3 и API через `curl --http2`.
- **Codex.** `codex exec` без закрытого stdin зависает на «Reading additional input from stdin…»; запускать с `< /dev/null`.
- **ENOSPC при деплое генератора.** Несжатый `generator.tar` вырос до 4,4 ГБ: `generator-data/ops-backups` уже 2,3 ГБ, адресный индекс с Казанью — 126 МБ. На 2,7 ГБ свободных gzip упал после перезапуска генератора: сервис был healthy, бэкап не дожат. Освобождено удалением самого старого деплойного бэкапа (его удалила бы ротация), затем `flock -n .deploy.lock bash generator-backup.sh finalize …`.

- **Аудит K03/K04 (13.10).** Codex поймал то, что повторялось и в тексте, и в `claim`: дату теории Бутлерова (статья о Химическом институте пишет «к 1858 году», а теорию он изложил в Шпейере в 1861-м), «крупнейшую площадь» и расхождение двух статей о том, где стоял старый театр. Совпадение рассказа с claim не доказывает факт: спорное сверять со второй статьёй.
- **PROVIDER_BUSY при свободных кредитах (13.10).** Очередь K03/K04 в первые минуты получала HTTP 429 от ElevenLabs, хотя на четырёх ключах было свободно около 157 тыс. символов; через несколько минут пошло само, четыре записи прошли со второй попытки. Остаток кредитов смотреть бесплатным `GET /user/subscription` через прокси с `Accept-Encoding: identity`: иначе прокси отдаёт сжатое тело без заголовка и JSON не разбирается.
- **Подпись фото.** Тест каталога требует `alt` длиннее пяти символов: «Манеж» не проходит, нужна «Манеж Казанского кремля».

## Риск и исправление

Деплойный бэкап пакует весь `generator-data` вместе с `ops-backups` и требует свободного места примерно на два размера несжатого tar. В репозитории сервисов (коммит 904cde0) деплой генератора теперь до остановки сервиса сравнивает нужное место (данные, прошлый архив × 1,2 и 512 МиБ запаса) со свободным и при нехватке отказывается без простоя. Исключать `ops-backups` из архива не стали: это противоречит тесту «nested database copies are kept», поэтому папку по-прежнему чистят перед деплоем.

## Купленный тур IZI «Казанский кремль. Камчатские экспедиции»

- **Чтение.** Тексты глав страница не содержит. Их отдаёт `POST /ru/izi_apicontent/stop` с телом `{"uuid": "<глава>__<тур>", "prev", "next", "lang": "ru"}`, и только залогиненному покупателю (`drupalSettings.iziRewardedAds.hasPurchase: true`). UUID глав лежат в `drupalSettings.iziMtgInfoChildren`, порядок задают ссылки `#<глава>__<тур>`. Тексты платные, в репозиторий их не кладём: локальная копия лежит в `artifacts/kazan-center/izi/`.
- **Сверка с K01, 13.10.** В 12 главах фактических противоречий с рассказами K01 нет. Совпадают: Ширяй и Яковлев у Благовещенского собора, коленчатый проезд Спасской башни, двухметровое отклонение шпиля Сююмбике, Зилант на шпиле Пушечного двора, остатки Преображенского собора. Расхождение только в трактовке датировки башни Сююмбике: тур опирается на Сергея Саначина (конец XVII — начало XVIII века), K01 говорит о споре в целом, и это не ошибка. Переозвучивать K01 не нужно.
- **Материал для этапа 2.** В K01 нет глав про Тайницкую башню (ханская башня Нур-Али, подкоп 1552 года), Губернаторский дворец Константина Тона, Дворцовую церковь (по плану 1768 года «обращённую из мечети»), Троице-Сергиев монастырь на месте Кул-Шарифа, гауптвахту и Якова Шейнкмана. Ещё есть видимые с улицы детали: отмеченное на брусчатке место колокольни Благовещенского собора и псковский орнамент на его фасаде. Их стоит проверить по открытым источникам и использовать для кремлёвских точек следующей очереди.
