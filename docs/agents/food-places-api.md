# API ячеек заведений: фаза 2

Реализована только серверная фаза 2 плана `plans/2026-10-04-food-along-walk.md`. Интерфейс, загрузчик клиента, часы работы и офлайн-пакеты относятся к следующим фазам. Коммит, выкладка и обращения к production не выполнялись.

## Контракт

`backend/food-places.mjs` открывает `DATA_DIR/osm-food.sqlite` только для чтения. Проверяет `meta.format_version=1`, дату `source_edited_at`, атрибуцию, доступность колонок и координаты. Отсутствующий файл отключает функцию; несовместимый или повреждённый индекс останавливает запуск с `FOOD_INDEX_INVALID`, без раскрытия пути и содержимого базы. SQLite закрывается при штатной остановке backend.

- `GET`/`HEAD /api/food/cells`: `{version:1,cellSize:0.05,sourceEditedAt,attribution,cells:[{lat,lon,count,etag}]}`. Дата и атрибуция берутся из `meta` без подмены.
- `GET`/`HEAD /api/food/cells/{latKey}/{lonKey}`: `{lat,lon,places:[...]}`. Поля заведения: `id,kind,name,lat,lon,address,openingHours,cuisine,website,phone`; необязательные значения остаются `null`, порядок заведений — по `id`.
- Ключи — `floor(coord * 20)`, диапазоны широты `[-1800,1799]`, долготы `[-3600,3599]`. Как в map-cells, крайние координаты +90/+180 относятся к последней ячейке. Проверяются точные границы, значения с обеих сторон, отрицательные координаты и полюса.
- Query-строка, включая пустой `?`, ведущие нули, `-0`, дроби, неправильный путь и ключи вне диапазонов дают 400. Проверка пути выполняется и при отключённом индексе.
- Отсутствующий индекс: 503 `{"error":"FOOD_INDEX_UNAVAILABLE"}`, `Cache-Control: no-store`, без ETag. Основной сервер продолжает работать.

Используется существующий `http-cache.mjs`: `no-cache`, ETag, 304, `Vary: Accept-Encoding`, br/gzip. ETag каждой ячейки в манифесте совпадает с её HTTP-заголовком без внешних кавычек. Манифест и заполненные ячейки сериализуются один раз при открытии; обновление файла подхватывается после перезапуска. Для пустых ячеек кеш ограничен 128 записями: произвольные публичные запросы не должны бесконечно увеличивать память процесса.

В `docker/nginx.conf` добавлен `/api/food/` с теми же proxy/security snippets, что у map-cells. Общий `/api/` раньше уже проксировал бы этот путь, но заменил бы Cache-Control на `no-store`. Новое правило сохраняет заголовки backend и не добавляет кеш nginx. `compose.yaml` уже подключает frontend к backend и монтирует `DATA_DIR`; изменение не требуется.
