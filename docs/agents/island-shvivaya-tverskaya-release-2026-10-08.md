## Выполнение

Созданы 43 отдельные адресные редакции по устойчивым ключам. 42 новых задания синтеза завершились, одна неизменённая запись v4 Библиотеки иностранной литературы переиспользована. Прямое указание пользователя использовать v4 относится к этой очереди и разрешает замену v3 в отдельных редакциях; общий каталог и существующие записи не переозвучивались.

Перед импортом и после выпуска проверены 43 исходные карточки, их утверждённые тексты и звук, 25 публичных прогулок, две предыдущие общие ссылки серии и 6292 OSM-псевдонима. Исходные записи сохранились. Применён целевой JSON-снимок затрагиваемых строк, без новой полной копии SQLite; каталог операции закрыт правами 0700/0600.

Каждый MP3 проверен по доступности, размеру, SHA-256, фактической длительности и соответствию исходному/подготовленному тексту. Проверены настоящий провайдер, модель и голос, включая переиспользованную запись. Голос основного аккаунта до синтеза подтверждён через API, перед завершением проверены также две резервные копии «Отголосок2»; строка профиля `elevenlabs-v3` является прежним идентификатором, фактическая модель задания — `eleven_v4`.

## Наблюдения и исправления

Семь опубликованных коротких текстов имели `effectiveProfile: story-v1` при объёме меньше 100 слов и не проходили действующий `hasValidStoryText`. Только новые копии получили `description-v1`, без изменения абзацев. Корректное дальнейшее исправление — отдельный аудит старых профилей с проверкой их потребителей; массовая правка общего каталога не выполнялась.

У трёх обогащённых рассказов сняты прежние метаданные короткой справки; у Дмитрия Донского формулировка факта приведена к тому же осторожному указанию на предание, что и озвученный абзац. Метаданные исправлены штатным обновлением только после завершения соответствующей очереди, при проверке неизменности абзацев и MP3. Исправление метаданных активного источника до приёма звука привело бы к конфликту ревизии и потому не применялось.

В разных рассказах оставались переходы прежних прогулок: Пятницкая у Смирнова, старый маршрут у Всех Святых, будущее упоминание Страстного бульвара. Исправлены только отдельные маршрутные версии. В семь других новых копий внесена только корректировка профиля, без редактирования текста.

Для HTTP-запроса списка голосов в Node 24 на сервере использован `fetch` из установленного undici вместе с клиентом ElevenLabs. Встроенный `fetch` в сочетании с установленным ProxyAgent давал ошибку совместимости декомпрессии; рабочий TTS-процесс и прокси не менялись. Правильное отдельное исправление — использовать согласованную связку `fetch` и `ProxyAgent` из одной версии undici для клиента списка голосов и покрыть её контрактной проверкой. Подробности предыдущей проверки голосов находятся в [выпуске Остоженки и Поварской](ostozhenka-povarskaya-release-2026-10-08.md).

## География и проверки

Проверка интерфейса сначала ожидала «К финишу» у Тверской и остановилась на этом предположении. Вход в «Маяковскую» находится в 17,86 м от последнего триггера, поэтому штатный `hasFinishLeg` сразу предлагает «Завершить». Повторный полный проход проверяет адрес метро в списке остановок до старта и завершённое состояние после последней главы; изменение поведения приложения не требуется.

Дом на набережной привязан к северному фасаду того же большого OSM-здания; тротуар в 2,16 м от его контура исключает лишний обход до южного центра. У Котельнической высотки и Воспитательного дома выбраны публичные набережные, у МХТ — пешеходный Камергерский. Доступ во двор Саввинского подворья не обещан. Все центры, триггеры и вершины линий внутри Садового; точные выходы метро и подходы проверены кабинетно.

Между новыми тремя прогулками 0% общих объектов, с прежними максимум 25%, с другими проектами плана максимум 7,69%. Отдельные задания сохраняют физический `placeId` и не являются новыми точками для матрицы.

Публичный API подтвердил точное совпадение документов, всех текстов и хешей MP3. Мобильный Chrome 390 × 844 прошёл чтение и воспроизведение всех 43 рассказов, паузу, последовательность и финишное метро; ошибок JavaScript и HTTP для звука нет. Полный `pnpm check` прошёл: 1984 frontend-теста, 1054 backend-теста, 26 Python-тестов и 78 подтестов, lint/typecheck и production-сборка. У ESLint 127 существующих предупреждений, ошибок нет.

Новый независимый аудит Claude Code Opus 5.5 не выполнен: CLI вернул недельный лимит и код 1, модель не подтверждена. [Квитанция отказа](../../content/island-shvivaya-tverskaya-2026-10-08/claude-audit-unavailable.json) и собственная редакционная проверка сохранены раздельно.
