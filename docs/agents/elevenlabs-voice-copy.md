# Копия голоса «Отголосок2» на ключе другого аккаунта

ID голоса у каждого аккаунта ElevenLabs свой. Чтобы новый ключ озвучивал «Отголосок2», в его аккаунте создаётся мгновенный клон (`POST /v1/voices/add`), а ключ вносится в `ELEVENLABS_API_KEYS` как `ключ:ID_копии`.

Все копии сделаны из одного исходного сэмпла `otgolosok-production-3m58s.mp3` (1 901 229 байт, лежит локально в `.orca/drops/`). API скачивания сэмпла (`/v1/voices/{id}/samples/{sample_id}/audio`) отдаёт перекодированный файл в 5,7 МБ, поэтому клонировать нужно из оригинала, а не из скачанного файла. Параметры копии: имя «Отголосок2», `remove_background_noise=false`, метки `language=ru`, `accent=ru-standard`, `gender=male`, `age=middle-aged`. Настройки голоса по умолчанию (stability 0.5, similarity 0.75, style 0, speaker boost) совпадают с исходным голосом без отдельной правки.

Создание клона кредитов не тратит. После создания стоит проверить карточку голоса (`GET /v1/voices/{id}`: сэмпл того же размера, те же метки) и синтез короткой фразы моделью `eleven_v4` этим ключом.
