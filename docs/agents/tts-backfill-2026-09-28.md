# Массовая озвучка коротких описаний, 28 сентября 2026 года

На момент проверки в production было 1495 текстов и 1252 аудиозаписи. Из 243 текстов без аудио 186 были утверждёнными короткими описаниями (`audioDisposition: not_applicable_short_text`), остальные 57 не были утверждены. Аудиозаданий для этих 243 текстов не было. Транспорт HTTP, профиль `f5-ru-v1` и TTS API были доступны; минимальный порог длительности публикации уже снят.

Первый запуск `enqueueMissingPlaceAudio()` для 10 описаний вернул 10 ошибок. Все первые записи содержали один абзац, а `hasValidStoryText()` принимала минимум два абзаца для любого профиля. Проверка всех 186 утверждённых описаний показала 14 однопараграфных, 92 двухабзацных и 80 трёхабзацных. Из них 172 были поставлены в очередь прежним кодом; 14 получили `BAD_REQUEST` без создания задания.

Исправление `5288631` разрешило один абзац только для `description-v1`, сохранив ограничение в два абзаца для полного рассказа. Тест воспроизвёл отказ до исправления; после него линтер, проверка типов и все 377 тестов прошли. Backend выложен штатным скриптом с резервной копией `backups/generator-20260928T114602Z/generator.tar.gz`. После выкладки остальные 14 описаний успешно поставлены в очередь: `queued: 14`, `failed: 0`.

Последняя проверка: 1497 текстов, 1262 аудиозаписи, 175 заданий `queued`, одно `leased`, 59 неутверждённых текстов без аудио. Утверждённых текстов без аудио и без задания — ноль. Контейнер генератора был healthy через две минуты после выкладки. Эти числа отражают только момент проверки: озвучка продолжалась.

До выкладки контейнер генератора несколько раз перезапускался после исчерпания лимита памяти Node при загрузке чекпоинтов для статистики.
