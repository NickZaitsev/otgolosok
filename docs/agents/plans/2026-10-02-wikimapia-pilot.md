# План: пилот Wikimapia для точек без рассказов

Status: in progress since 2026-10-02, выборка подготовлена; выполняется загрузка и проверка источников.

> План фиксирует состояние проекта на дату создания. Перед продолжением работы перепроверьте факты по актуальному коду.

## Контекст

Пользователь подтвердил право перерабатывать тексты Wikimapia для сервиса и поручил провести предложенный пилот на 30–50 точках без рассказов. Проверка `https://api.wikimapia.org/` показала работоспособность `place.getbyid` и `place.getnearest` с публичным ключом `example`; страницы документации отвечают HTTP 429. Собственный ключ в локальных `.env*` не найден.

## Согласованные решения

1. Проверить сопоставление существующих точек и полезность текстов до полноценной интеграции.
2. Сохранять ссылки и исходные описания. Разрешение пользователя относится к текстам; фотографии не включать.
3. Для пилота достаточно локальных артефактов исследования; публикация рассказов и изменение production-базы в эту работу не входят.

## Проверенные факты проекта

- `backend/content-store.mjs` хранит объекты в `places`, редакции в `place_texts`; отсутствие текста определяется через `NOT EXISTS` по `place_id`.
- `scripts/prod-db.mjs` показывает способ чтения production через SSH и Node в контейнере. Для пилота достаточно одного read-only SELECT с ограничением по координатам, без копирования базы.
- `backend/data/` уже исключён из Git; локальные ответы API сохраняются в `backend/data/wikimapia-pilot/`.
- `backend/retry.mjs` содержит ограниченные повторы и задержки; `backend/open-data.mjs` экспортирует `distanceMeters`.
- `pnpm check` проверяет lint, типы, frontend/backend-тесты, Python и production-сборку.

## Реализация

1. Выгрузить из действующей базы только публичные поля неархивных точек без редакций в прямоугольнике 55.68–55.82° N, 37.48–37.75° E. Из 2308 точек выбрать воспроизводимую выборку 40: 20 мемориалов, 10 произведений искусства, 10 остальных; порядок SHA256 от `wikimapia-pilot-v1:<id>` внутри групп.
2. Добавить `backend/wikimapia-pilot.mjs` с небольшим клиентом API, проверкой ответов, безопасными сообщениями ошибок без ключа, ограниченными повторами сетевых ошибок, тайм-аутов, 429 и 5xx. Сериализовать запросы; для `example` выдерживать не менее 31 секунды. Ключ читать из `WIKIMAPIA_API_KEY`, тестовый доступ включать явно.
3. Добавить `scripts/probe-wikimapia.mjs`: входной JSON выборки, кеш успешных ответов, возобновление без повторной загрузки, поиск ближайших объектов, загрузка описаний кандидатов и итоговый JSON. Не сохранять фото, комментарии и пользовательские профили. Кандидатов выбирать по названию и координатам, оставляя неоднозначность для ручной проверки.
4. Вручную проверить сопоставления и содержательные описания. Сохранить компактный проверяемый результат в `content/wikimapia-pilot-2026-10-02/`, методику, числа и ограничения в `docs/agents/wikimapia-pilot.md`; добавить заметку в индекс.

## Проверки

Тесты клиента и сопоставления: успешный ответ, пустой результат, несовпадение имён, далёкий одноимённый объект, неоднозначность, невалидные координаты, ошибки HTTP и API внутри HTTP 200, повторы и отсутствие ключа в ошибке. Живые API не вызывать из тестов. Выполнить полный `pnpm check`, проверить все 40 результатов и сохранить атомарные коммиты в текущей ветке.

## За рамками

Массовый импорт, схема production-базы, автоматическая публикация, фотографии, генерация аудио и платные вызовы моделей.
