# Точки у «Спартака» и «Тушинской», 04.10.2026

По просьбе пользователя просмотрены OSM, Wikidata, Wikimapia и data.mos.ru в радиусе 1,5 км от станций
«Спартак» и «Тушинская» и подготовлены 23 рассказа от 50 секунд; в тот же день они опубликованы и озвучены F5. Результат —
[content/tushino-spartak-2026-10-04/README.md](../../content/tushino-spartak-2026-10-04/README.md). В каталоге планировщика (`walk-discovery-catalog.json`) в этом
радиусе не было ни одной точки.

## Наблюдения по источникам

- **Overpass** (`overpass-api.de`) 4 октября отвечал HTML-страницей с ошибкой `Dispatcher_Client::request_read`
  вместо JSON. Выборку сделали из локального `backend/data/geocoding/Moscow.osm.pbf` через
  `uv run --with osmium` (пакет `osmium` в проекте не установлен).
- **Wikimapia `box`** с ключом `example` отдаёт по 100 объектов на страницу. Третья страница через 32 с получила
  «You need to wait for 15 seconds», так что лимит считается не только по интервалу. В рамке 1,5 × 2,9 км было
  1 245 объектов; первые 200 — крупные контуры (кварталы, заводы, парки), памятников среди них почти нет.
  В ответе `box` нет описаний, только `id`, `name`, `location`, `polygon`; описания читаются через
  `place.getbyid`. Карточку аэродрома (118403) прочитать не удалось: четыре повтора упёрлись в лимит.
- **apidata.mos.ru** не отдаёт промежуточный сертификат, `curl` на macOS падает с кодом 60 даже с `--cacert`
  (см. [data-mos-open-data.md](data-mos-open-data.md)). Python `urllib` работает с CA-файлом из корней GlobalSign
  системной связки macOS и промежуточного сертификата по AIA
  (`http://secure.globalsign.com/cacert/gsgccr6alphasslca2025.crt`); проверку TLS не отключали.
- **Набор 530** по координатам дал рядом только три объекта: аэроклуб и два ДОТа. Ещё два объекта наследия —
  административное здание «Красного Октября» и дом Наркомвода — есть только в Wikidata (P1483), в наборе их
  контуров рядом нет.
- **Набор 2801:** у доски Покрышкину (Волоколамское ш., 88 к3 с3) дата установки 01.07.1963, а в тексте
  доски — работа здесь в 1972–1981 годах. Дата в наборе ошибочна; в рассказы её не брать.
- Факт о ДК «Красный Октябрь» как здании дирижабле-учебного комбината 1932 года найден только в Wikimapia
  (тот же текст повторяют агрегаторы). Для парашютной фабрики второй источник нашёлся — статья «Авиация России».

## Публикация

- Импорт требует объект OSM (`osmType`/`osmId` и алиас). Аэродром, рынок, парашютная фабрика и село Тушино
  своих объектов не имеют и привязаны к ближайшим реальным: Небесный бульвар, ул. Николая Озерова, 2 к1,
  Сходненский тупик, 1, Лётная улица. Название места задано редакцией.
- 6 из 23 мест уже были в каталоге (пять памятников без текста и Сходненская ГЭС с автоматическим
  рассказом), поэтому пакет делится на `place` и `expected`; snapshot перед apply обязателен.
- `artifacts/boulevard-trubnaya/remote.py` читает stdin целиком: без `</dev/null` команда без входных данных
  зависает до таймаута.
- Точки вне промопрогулок озвучиваются `loadLocalTtsConfig(...).defaultProfile` (`f5-ru-v1`). 23 задания F5
  выполнились за ~15 минут, все с первой попытки. Квитанцию задания удобно сверять по `upload_sha256` в
  `external_audio_jobs` и `audio_json.sha256` текущей редакции.
- Операционные скрипты и выгрузки — в игнорируемом `artifacts/tushino-spartak/`, резервная копия строк —
  `/data/ops-backups/tushino-spartak-2026-10-04/before.json` в томе генератора.
