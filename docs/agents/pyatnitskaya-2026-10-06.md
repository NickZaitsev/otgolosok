# Пятницкая от метро до метро

По просьбе пользователя создана прогулка «Пятницкая: деньги, книги и городская жизнь»: [публичная ссылка](https://otgolosok.online/walk?share=85429f29-1bb3-41dc-a08b-2c4cb13b67d0), [редакционный пакет](../../content/pyatnitskaya-2026-10-06/README.md). Одиннадцать остановок от «Добрынинской» до «Новокузнецкой»; 3215 метров, 42 минуты ходьбы, 2518 слов. Пересечений по ID с прогулками «Купцы и благотворители Ордынки» и «Вокруг Третьяковки» нет.

Пятницкая почти не входит в список 97 глав исходного гида. Поэтому восемь новых историй и три расширенные редакции написаны по открытым источникам; Черниговское подворье связано с главами 29, 31, 32. Подробности спорных адресов, строительных этапов и исторической идентификации перечислены в README пакета.

При проверке геометрии точка у восточной стороны типографии Сытина давала обход квартала. Точка перенесена к фасаду на Пятницкой, историческая геометрия корпуса сохранена; итоговый маршрут короче на 308 метров. Последняя остановка обозначает существующий вход метро, где рассказ объясняет утраченный храм Параскевы Пятницы. Полевая проверка доступности переходов отсутствует.

Пробный импорт откатывается целиком, конкурентная редакция отклоняется, повтор не создаёт новых текстов. Production-импорт добавил семь карточек и одиннадцать редакций; перед записью сохранены затронутые данные и база аккаунтов. Фото выбраны визуально по нужным корпусам и опубликованы с авторством и лицензиями; 22 публичных JPEG проверены по SHA-256.

Первоначальный выпуск фотографий выполнен под `.deploy.lock`, с проверкой отсутствия активных заданий и откатом при ошибке запуска. Параллельный выпуск сайта затем временно вернул 503 и заменил каталог версией без новых записей: API вернул `photo: null`. Также прерванная девятая аудиозадача дождалась десятиминутного истечения lease и успешно завершилась со второй попытки; вручную очередь не менялась.

Фотографии восстановлены под `.deploy.lock` через штатный `syncEditorialPlaceImages`, без перезапуска других активных заданий. Полный свежий каталог из текущего образа и редакционных строк базы объединён с дельтой, чужие записи сохранены. Корень работающего контейнера доступен только для чтения, поэтому каталог для импорта загружен в `/data`; для следующего запуска подготовлен образ с тем же кодом и новым каталогом, обновлены серверные исходники. Резервная копия: `backups/pyatnitskaya-photos-20261006-refresh/`. Для предотвращения повторения общий деплой должен объединять свежий фотокаталог под блокировкой непосредственно перед заменой образа и завершать активные задания перед перезапуском.

Все одиннадцать историй опубликованы с новым аудио ElevenLabs `eleven_v4`, голос «Отголосок2»: 1245,960 секунды, то есть 20 минут 46 секунд. MP3 скачаны и проверены по SHA-256, размеру и длительности ffprobe; API общей прогулки возвращает одиннадцать готовых глав. Старые аудиозаписи прежних редакций не засчитаны. Полный `pnpm check` прошёл: lint, TypeScript, 1758 Vitest-тестов, 966 backend-тестов, 26 Python-тестов с 78 subtests и статическая сборка.

На публичном сайте в мобильном viewport 390×844 пройдены все остановки: заголовки, тексты и источники совпадают с пакетом, фотографии загружаются и открываются с правильным авторством и лицензиями. Первая и последняя истории воспроизводятся и ставятся на паузу; ошибок страницы нет.
