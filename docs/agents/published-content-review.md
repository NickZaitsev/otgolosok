# Просмотр опубликованных текстов

Дата: 2026-09-18. Проверка выполнена при подготовке плана исправления причин проблем генерации.

## Объём и ограничения

Прочитаны все 28 опубликованных текстов для 28 OSM-объектов в локальной `backend/data/jobs.sqlite`: записи `place_texts.approved_story_json` с датами от 2026-09-16T14:21:52.182Z до 2026-09-18T14:27:33.138Z. База открывалась только для чтения с учётом WAL. В ней нет адресных заданий в `jobs` и дополнительных публикаций в `walk_chapters.published_json`.

Также прочитаны четыре базовых текста прогулки «От Кожевников к Цинделю» из `backend/builtin-routes.mjs`, сформированного из каталога маршрутов. Повторяющихся проблем OSM-пайплайна при этом просмотре в них не обнаружено; это редакционное наблюдение, а не подтверждение каждого исторического утверждения.

Это просмотр доступных локальных публикаций, а не сверка актуального production. Внешние страницы заново не загружались, звук не прослушивался. Для выбранных примеров дополнительно прочитаны сохранённые факты и цитаты из `evidence_json`; полного повторного исследования всех 28 объектов не проводилось. Старые тексты отражают несколько версий пайплайна, поэтому сами по себе не доказывают дефект последней версии.

## Решения пользователя

- Википедия как единственный содержательный источник допустима. Отсутствие официального или первичного источника само по себе не является дефектом и не требует сокращения текста либо запрета озвучки.
- Исправлять причины в генераторе; существующие проблемные публикации не переписывать и не перегенерировать.

## Наблюдения

| Пример | Наблюдение | Исправление причины |
| --- | --- | --- |
| «В год 70-летия победы в ВОВ» | Справка несколько раз пересказывает название и классификацию объекта. Четыре извлечённых факта — тип, посвящение из названия, категория справочника и район; самостоятельного рассказа за ними нет. | Различать идентификационные сведения и содержательные факты. Не считать перефразированное название материалом для истории; при его отсутствии завершать `insufficient_evidence`. |
| «А. И. Райкину» | Кирпичные стены и смешанные перекрытия дома заполняют справку о доске; повторно разъясняется, к чему относятся годы и характеристики. | Отбирать факты по связи с выбранным объектом и полезности слушателю; разрешать короткий результат без добора объёма. |
| «Борисов камень», «Памяти экипажа „Курска“», Artplay | Фразы «надпись относится к самому камню, а не к музею», «самим объектом является мемориал», «разные объекты, связанные общей территорией» превращают внутреннюю проверку идентичности в речь экскурсовода. | Различать объекты естественными названиями и связками; оставлять пояснение только при реальной неоднозначности. |
| MEYN | Большая часть текста посвящена мебельной коллекции, остальное — соседнему «Римскому дому»; связь этих сведений с историей выбранного места слаба. | Проверять предмет рассказа, а не только допустимое значение `topic` или расстояние до соседа. Контекст не должен подменять выбранный объект. |
| «Институт психологии РАН» | После адреса следуют даты реорганизаций, номер постановления и список директоров. Это подтверждённые сведения, но их отбор плохо приспособлен к короткому рассказу на прогулке. | Предпочитать понятные события и объяснение значения места; не требовать обязательной биографии, хронологии или нескольких источников. |
| «Иоасафовская башня», «Большой Кремлёвский дворец», «Дом воинской славы» | Необъяснённые термины и длинные перечни: «своды типа Монье», «каре», «двусветные залы», отделка «под шубу». | Проверять пригодность для восприятия на слух; упрощать, кратко объяснять по источнику или опускать деталь без потери смысла. |
| Бахрушинский музей | «Приобрёл для охраны усадьбы пару английских львов; один сохранился» допускает прочтение о живых животных. Сохранённая цитата начинает этот фрагмент словами «деталью украшения садово-парковой части усадьбы», но при извлечении и пересказе этот контекст теряется. | Сохранять предмет и смысл метафор источника. Когда тип предмета нельзя уверенно установить из доступного контекста, опускать спорную деталь, а не дописывать объяснение из памяти модели. |
| «Музей автомобильных историй» | Смешаны сведения о музее и пространстве «Детство» по одному адресу, но их отношение не объяснено. «Реставрации уделили достойное место» в источнике превращается в «пространство для реставрационных работ» в тексте, чего цитата не устанавливает. | Проверять отношение объектов и точное значение утверждения; упоминание реставрации в экспозиции не подтверждает существование мастерской. Не устанавливать тождество только по адресу. |
| «Иоасафовская башня», «Рабочий и колхозница», «Институт психологии РАН» | Адрес находится в первом абзаце, но его `factIds` ссылаются на другие утверждения. | Представлять адрес отдельным доказанным утверждением и связывать его с текстом; служебное `resolvedAddress` само по себе доказательством не является. |

Примеры для воспроизведения: «В год 70-летия…» — `osm:node:4796203282`, публикация `3cfb8190-87ef-4453-8007-df5a5adb44fe`; Бахрушинский музей — `osm:node:273356351`, публикация `cb7c99f2-5122-43f2-a498-af61402ed17f`; Музей автомобильных историй — `osm:node:5682498988`, публикация `cda02079-43dc-4d23-8ec0-e8e6f8eef431`. Полные базы, checkpoint и исходные страницы в Git не добавлять.

Из просмотра нельзя заключить, что конкретные даты Artplay или другие исторические сведения ошибочны: для этого нужна отдельная проверка источников. Полезно исправить перенос смысла и отбор материала, а не заменять спорные факты догадками.
