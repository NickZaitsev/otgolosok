# Прохождение прогулки с конца

На карточке универсальной прогулки до старта есть кнопка «Направление: с начала». Нажатие переключает её на «Направление: с конца»: остановки и линия пешеходного маршрута разворачиваются, старт и финиш меняются местами. Повторное нажатие возвращает исходный порядок. Во время прохождения переключатель скрыт, а направление сессии зафиксировано, даже если выбор изменён в другой вкладке.

`orientWalk` создаёт представление маршрута без изменения опубликованных данных. Номера остановок, геотриггеры, подсветка текущего участка, проигрывание подряд и дополнительный путь до финиша используют это представление. Индексы крытых переходов преобразуются относительно последней вершины развёрнутой линии. Координаты объектов, точки прослушивания и аудио сохраняют связь с исходной остановкой. Функция применяется и к кольцевым прогулкам.

Выбор хранится отдельно для каждой прогулки в `otgolosok:walk-direction:<routeId>`. При запрете записи, включая переполнение localStorage, действует выбор в памяти текущей страницы. Прямое направление использует прежний ключ прогресса `otgolosok:playback:<routeId>`, обратное — тот же ключ с суффиксом `:reverse`. Старые записи совместимы; завершение обратного прохода не удаляет прогресс прямого. Офлайн-копия остаётся общей: дополнительных файлов или запросов для смены направления нет.

Подсказки `transition` и `next_hint` исходного направления в обратном представлении очищаются. Записанное аудио и текст рассказов не редактируются: если рассказ содержит указания направления или обращения к предыдущим остановкам, нужна отдельная редактура и озвучка обратной версии. Сам маршрут используется в точности по существующей пешеходной линии, без повторного запроса к маршрутизатору.

Проверки: модульные тесты разворота, тоннелей, кольца, пустого маршрута, сохранения и ошибок хранилища; браузерные тесты полного обратного прохода, восстановления прогресса после перезагрузки и запуска последнего рассказа по геопозиции. При тихой разблокировке аудио `paused` может уже стать `false`, пока `currentSrc` ещё пуст: браузерный помощник считает воспроизведение рассказа начавшимся только при непустом источнике, отличном от тихого `data:`-клипа.
