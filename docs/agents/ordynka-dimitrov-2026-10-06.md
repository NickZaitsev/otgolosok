# Памятник Димитрову: рассказ, фото и тринадцатая остановка

Пользователь поручил добавить `osm:node:1359108784` между новым корпусом Третьяковки и храмом Григория Неокесарийского, расширить рассказ, подготовить превью и озвучку. Памятник Георгию Димитрову в Якиманском сквере включён под номером 12; храм стал остановкой 13. Прежние двенадцать остановок и их последовательность сохранены.

Рассказ расширен со 110 до 263 слов, переведён из автоматической проверки в редакционную. Источники и связи абзацев с фактами сохранены в [extension-stories.json](../../content/ordynka-tretyakovka-2026-10-04/extension-stories.json). Газетный репортаж «Зари Востока» от 18 июня 1972 года, с. 2, подтверждает дату открытия 16 июня, авторов, образ оратора, участие представителей СССР и Болгарии и исполнение двух гимнов. Немецкий исторический музей подтверждает оправдание на Лейпцигском процессе и объясняет последующий героический образ в коммунистической Болгарии. История портрета 1934 года, тогдашнее название улицы и проживание в Доме на набережной проверены по статье с библиографией московских путеводителей. Точные годы переименования улицы не включены: найденные городские документы расходятся.

Фото самого памятника найдено внутри общего снимка Якиманского сквера: `Moscow, Bolshaya Yakimanka Street (31040897071).jpg`, Gennady Grachev, CC BY 2.0. Исходник проверен визуально, подготовлены кадр 960 × 640 и отдельное широкое превью 500 × 166. Фигура и постамент целиком помещаются в широком кадре. Метаданные, авторство, лицензия и описание обрезки внесены в редакционный каталог и [previews.json](../../content/ordynka-tretyakovka-2026-10-04/previews.json).

Пробный импорт в изолированной SQLite-базе подтвердил откат dry-run, отказ при конфликте исходной версии и повторное применение без новой редакции. Перед production-импортом сняты свежие ожидаемые версии места, утверждённого текста, всех черновиков и аудио; сохранена резервная копия затронутых строк. Операционная директория — `/data/ops-backups/ordynka-dimitrov-2026-10-06/`.

Новая запись ElevenLabs «Отголосок2», `eleven_v4`, длится по API 138,384 секунды, то есть 2 минуты 18 секунд. Синтез завершился с первой попытки. Все тринадцать MP3 скачаны, сверены по SHA-256 и размеру; длительность измерена ffprobe. Сумма по API — 1071,216 секунды, измеренная сумма — 1070,48 секунды, то есть 17 минут 50 секунд. Прежние двенадцать SHA-256 совпадают со снимком API на начало задачи.

Valhalla рассчитала 2371 метр и 31 минуту ходьбы. Маршрут подходит к назначенной точке у памятника с отклонением 6,86 метра. На прогулку с рассказами и осмотром предусмотрено 60–75 минут; полевая проверка не выполнялась.

Дополнительный тест пакета сначала воспроизвёл отсутствие остановки, затем проверил её место между двумя объектами, расширенный редакционный текст, фото с лицензией и готовую озвучку.

Полный `pnpm check` завершился успешно: линтеры, проверка типов, тесты и production-сборка. Прогулка опубликована в редакции 7 по прежнему share-токену и остаётся в каталоге популярных прогулок. Публичный API подтвердил точное совпадение документа, 13 готовых глав и готовые записи; два JPEG на сайте побайтово совпадают с файлами пакета.

В браузере 390 × 844 проверены список из 13 остановок, выбор остановки 12, загрузка фотографии, ссылки Commons и CC BY 2.0 и воспроизведение новой MP3: правильный SHA-256 в URL, `paused=false`, позиция растёт, ошибки плеера нет. Геопозиция тестового браузера недоступна; ручной переход работает.

Превью выпущено отдельным слоем поверх текущего образа генератора с сохранением остальных записей каталога. Резервная копия каталога и строк фотографий: `/srv/sites/otgolosok.softmg.tech/backups/ordynka-dimitrov-photos-20261006/`. Контейнер прошёл проверку здоровья; постоянный исходный каталог в `generator-backend` обновлён. Копирование в необязательный `generator-backend-next` сначала вернуло ошибку отсутствия директории после успешного выпуска: операционный скрипт исправлен, перед обновлением необязательного каталога проверяется его наличие.
