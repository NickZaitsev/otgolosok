## Наблюдения

- Глава прогулки в публичном API не содержит провайдера и модели; их нужно брать из карточки места и сверять по SHA-256.
- `urllib` Python получает от production HTTP 505; запросы выполнять через `curl --http2`.
- Команда `sh -c '...'`, переданная через ssh-обёртку аргументами, теряет кавычки; скрипты передавать в контейнер через stdin (`docker exec -i ... sh -s` или `node --input-type=module -`). Иначе можно случайно выполнить другую команду, например вывести всё окружение с секретами.
- В остальных промопрогулках на 7 октября оставалось около 103 записей v3; по новому правилу их нужно заменить отдельной партией после подтверждения списка и стоимости.
