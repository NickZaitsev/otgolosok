# Обновление строк черновиков без мигания таблицы

После утверждения текста `DraftsAdmin` удаляет выбранную строку из локального состояния. Остальные строки сохраняют DOM; повторного запроса списка нет, кроме возврата с опустевшей страницы на предыдущую. Пагинация хранит фактические начала посещённых страниц и учитывает удалённые строки, чтобы переход вперёд не пропускал следующий черновик.

После обычного, глубокого и массового переисследования список сверяется с сервером без заглушек загрузки. Это сохраняет строки и обновляет статусы, фильтры и счётчики. Сообщение об успешной постановке в очередь появляется до сверки; если сверка не удалась, сообщение сохраняется рядом с ошибкой, которую показывает общий обработчик админки.

`researchEligible` в ответе списка вычисляется по тем же условиям, что `unresearched`: есть задание в завершённом состоянии и нет успешного исследования Perplexity. Статуса `plain` недостаточно: у текста может не быть задания, а текст в очереди уже исключён из массового переисследования. При утверждении этот признак позволяет правильно уменьшать счётчик без повторного запроса.

Проверки: регрессионные тесты компонента для сохранения строк, ошибок, границ пагинации и счётчиков; тест хранилища для соответствия `researchEligible` счётчику; браузерный сценарий с ошибкой утверждения и задержкой сверки после переисследования. Браузерный сценарий использует изолированные ответы API и не изменяет production-данные.
