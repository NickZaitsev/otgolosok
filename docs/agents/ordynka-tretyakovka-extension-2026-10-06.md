# Третьяковка: двенадцать точек и пятнадцать минут озвучки

Пользователь уточнил требования к прогулке `6cacfdd1-defd-4afb-940f-5085356d0315`: добавить истории до памятника Шмелёву и после приюта, минимум десять остановок и пятнадцать минут озвучки. Подготовлен маршрут из двенадцати остановок: усадьба Долговых-Жемочкиных и церковь «Всех скорбящих Радость», семь прежних историй подряд, «Деревья любви», новый корпус галереи на Кадашёвской набережной и храм Григория Неокесарийского. Ссылка, название и метро на концах сохранены.

Пять дополнительных текстов взяты из опубликованного каталога и сохранены в [extension-stories.json](../../content/ordynka-tretyakovka-2026-10-04/extension-stories.json). Училище Хлудова не включено: существующая запись заканчивается переходом к лаборатории Аршинова, которая не входит в этот маршрут. Это позволило сохранить согласованность повествования без изменения другого тура.

Valhalla рассчитала 2243 метра и 29 минут ходьбы. Центры объектов сохранены отдельно от уличных точек прослушивания; максимальное отклонение пешеходной линии от них — 6 метров. Полевая проверка не выполнялась; `fieldChecked: false`. На прогулку с рассказами и осмотром предусмотрено 55–70 минут.

Усадьба Долговых уже имела ElevenLabs «Отголосок2». Для остальных четырёх дополнительных остановок поставлены штатные идемпотентные задания ElevenLabs; все завершились с первой попытки, без ошибок. Семь исходных текстов и SHA-256 записей сверены со снимком публичного API на начало этой задачи, не изменились. Перед постановкой сохранены опубликованные карточки с прежним аудио; директория операций — `/data/ops-backups/ordynka-tretyakovka-extension-2026-10-06/`.

Двенадцать публичных MP3 скачаны, проверены по SHA-256 и размеру. Сумма длительностей из API — 932,832 секунды; независимое измерение ffprobe — 932,16 секунды, то есть 15 минут 32 секунды. Разница для отдельного файла меньше секунды; обе суммы превышают 900 секунд. В квитанции записаны обе величины.

Прежняя квитанция в репозитории описывала ранние записи `eleven_v3`, тогда как API на начало задачи уже отдавал `eleven_v4` для прежних семи остановок. Поэтому сохранность проверялась относительно свежего публичного снимка, а архивная квитанция обновлена по фактическим файлам. При следующем изменении нужно снова снять текущие SHA-256, а не считать старую квитанцию доказательством текущего состояния.

Тест [ordynka-tretyakovka-package.test.mjs](../../backend/ordynka-tretyakovka-package.test.mjs) воспроизвёл нарушение требования на семи остановках, затем прошёл на расширенном пакете. Он проверяет минимум десять уникальных озвученных историй, сумму от 900 секунд, единый голос, SHA-256 записей, сохранённый блок семи остановок и новые истории по обе стороны от него. Production dry-run подтвердил двенадцать готовых глав и совпадение версии 3 с исходным документом.

Полный `pnpm check` прошёл: линтеры, TypeScript, frontend- и backend-тесты, Python-проверки и сборка. После публикации версия 5 подтверждена публичным API: документ совпадает с пакетом, все двенадцать глав `ready`, их SHA-256 совпадают с квитанцией, прогулка остаётся в топе. На ширине 390 × 844 проверены список всех двенадцати остановок, метро на концах, карточка последней истории и воспроизведение её нового MP3 без ошибок.
