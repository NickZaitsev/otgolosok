# Публикация прогулки от «Текстильщиков» до «Волжской»

9 октября 2026 года опубликована [прогулка «От заводского клуба к крепостному театру»](https://otgolosok.online/walk?share=7cabbb84-06c4-445d-abf4-faf49a98aa5c). Штатный Valhalla построил маршрут 5 921 м, 70 минут ходьбы, 12 остановок от метро «Текстильщики» до метро «Волжская». Натурной проверки подходов не было, поэтому в документе `fieldChecked: false`; здания предлагается осматривать снаружи. Маршрут и исходные тексты находятся в [пакете выпуска](../../content/tekstilshchiki-volzhskaya-stories-2026-10-08/README.md).

Каждая из 12 глав публичного API имеет статус `ready`, рассказ от 100 слов и аудио ElevenLabs `eleven_v4`, голос «Отголосок2». В поле `voice` сохранён логический ID `9ivxhQ6xIsHd6R3Xc635`, а в метаданных — фактический ID подтверждённой резервной копии `JVYtLnrrrMG4dcGbtdAw`. Файлы сверены с исходной квитанцией по SHA-256 и размеру через публичный HTTPS; суммарная измеренная длительность 923,20 с (15:23). Для семи существовавших мест новая редакция вместе с готовым MP3 добавлена атомарно, девять прежних F5-записей и их файлы сохранены в истории. Пять мест добавлены в каталог, все 12 видны в публичной ячейке карты.

Пробное применение сверило контрольные хеши мест, редакций и активных заданий, затем откатило транзакцию. Фактический импорт сохранил адресный снимок прежних строк до записи; повторная публикация прогулки защищена ключом идемпотентности. У парка имени Шкулёва прежняя опорная точка каталога стояла у восточного края протяжённого полигона, более чем в километре от остановки. Для этой редакции её переместили на западную дорожку, сохранив полигон. При будущем полном импорте OSM следует снова проверить эту точку: автоматический выбор центра может вернуть восточный край и сделать главу недоступной из-за ограничения 100 м.

У 11 мест показаны фотографии. Семь новых кадров взяты из Wikimedia Commons с авторством и лицензией; оба размера каждого нового кадра и текущие фото остальных четырёх проверены через публичный API и HTTPS. Для московской скульптуры «Шурик и Лида» свободного снимка, достоверно относящегося к ней, не найдено; совпадающие по названию файлы Commons показывают Краснодар. Карточка и аудио этой остановки работают без фото. Публичный Chromium 390 × 844 прошёл 12 глав, запустил и остановил каждую запись, ошибок JavaScript не было.

Production-контейнер генератора имеет файловую систему только для чтения; редакционный каталог нельзя скопировать в работающий `/app/backend/`. Сначала строки фото синхронизированы с текущей базой без перезапуска, поскольку выполнялось другое аудиозадание. Первая синхронизация из старого каталога образа временно удалила две параллельно добавленные редакционные строки: обе сразу восстановлены из актуального рабочего каталога, публичные фото проверены, повторная синхронизация показала `removed: 0`. Подготовленный образ содержит объединение 296 записей, в том числе семь новых для этой прогулки и две параллельные. Правильное долговременное решение для адресных выпусков — добавить операцию точечного добавления фото без удаления остальных строк; до этого полный каталог нужно объединять со всеми опубликованными редакционными записями.

Перед пересозданием генератора 14 ожидавших аудиозаданий временно отложены с сохранением их исходных сроков; одно уже выполнявшееся задание завершилось без прерывания. Затем объединённый образ запущен под блокировкой выкладки, все 14 сроков восстановлены. После перезапуска в каталоге образа и базе остались 296 редакционных фото; обе параллельные карточки и 11 фото прогулки открываются публично. Повторная проверка прогулки подтвердила 12 готовых глав, 12 MP3 и завершение маршрута в мобильном Chromium без ошибок JavaScript.

## Исправление превью и названия реки, 9 октября

По замечанию пользователя для четвёртой остановки добавлена оригинальная редакционная иллюстрация двух студентов. Это не документальное фото московской скульптуры; карточка прямо обозначает изображение как иллюстрацию, показывает источник «Отголосок» и условия OpenAI. Нужную для этого проверку первого источника в редакционном каталоге ограничили собственным HTTPS-доменом и точным путём опубликованного JPEG. Новый образ генератора содержит 297 записей и сохраняет две параллельные редакционные фотографии; оба размера иллюстрации отдаются с сайта и загружаются в мобильном Chromium.

Для исправленного текста создан новый MP3 ElevenLabs `eleven_v4` голосом «Отголосок2»; предыдущая запись остаётся в истории и на диске. Опубликованная прогулка повторно проверена через API и браузер: 12 готовых глав, 12 доступных MP3, 12 превью, 924,88 с (15:25) аудио. Прогулка пройдена до финиша на экране 390 × 844 без ошибок JavaScript.
