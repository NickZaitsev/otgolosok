# Геолокация

## Разовое определение «где я»

Кнопка «Моё местоположение» на карте и в панели создания прогулки работает через
`locateOnce` из `src/lib/position/locate.ts`:

- сразу, в обработчике нажатия, уходят два запроса: грубый `getCurrentPosition`
  (`enableHighAccuracy: false`, кэш до минуты) и уточняющий `watchPosition` с GPS;
- грубая точка сразу показывается на карте, уточнение идёт до 6 с после первой точки
  или до точности 30 м;
- ошибка возвращается, только если не пришло ни одной точки; коды ошибок разные:
  нет API, запрет, позиция недоступна (обычно выключены службы геолокации ОС), таймаут;
- свой предельный таймер (20 с) запускается только после выдачи разрешения:
  время на окне «Разрешить?» не считается. Если `navigator.permissions` нет, ждём 45 с.

Прежняя реализация делала один запрос с `enableHighAccuracy: true` и таймаутом 12 с
(плюс свой таймер 13 с, считавший и время на окне разрешения). В помещении и на компьютере
GPS-точка часто не приходила вовремя, и пользователь видел «Не удалось определить положение».

Поиск историй рядом запускается, если погрешность не больше наибольшего радиуса (300 м);
радиус поиска поднимается до погрешности (`nearbyRadiusForAccuracy`). Раньше поиск
отключался уже при погрешности больше 50 м, то есть почти всегда на компьютере.

Слежение во время прогулки (`createBrowserPositionSource`) — отдельный механизм, его это не касается.

`positionIfGranted` — одна грубая точка только при уже выданном разрешении, без окна запроса;
ею пользуется подборка «Близко к вам» в создании прогулки ([nearby-walks.md](nearby-walks.md)).

## StrictMode и отмена в очистке эффекта

В dev-режиме React выполняет очистку эффекта с `[]` без настоящего размонтирования.
Если нажать кнопку сразу при гидрации, очистка отменяет уже запущенный поиск, а состояние
компонента остаётся «загрузка» навсегда. Поэтому очистка вместе с отменой сбрасывает
состояние загрузки. В e2e перед нажатием ждём исчезновения `.map-loading`: без этого
тест изредка ловил эту гонку в полном прогоне.

## Значок геолокации на карте — 8 октября 2026

Верхняя кнопка показывает красный перечёркнутый прицел при запрете доступа или
отсутствии Geolocation API. Неточная позиция (погрешность строго больше 50 м),
таймаут и недоступность позиции показывают охристый пунктирный прицел; точная
позиция возвращает обычный зелёный значок. Цвет дополнен формой и локализованным
текстовым статусом для скринридера и подсказки при наведении.

Браузер сообщает погрешность координат, а не силу GPS-сигнала или источник позиции.
Порог 50 м относится только к индикатору: радиусы поиска историй остаются прежними.
Это разовое определение позиции, поэтому значок описывает результат последнего
запроса, а не непрерывную диагностику GPS. Для показания текущей точности во время
прогулки используется отдельное слежение `createBrowserPositionSource`.

При наличии Permissions API экран читает разрешение без запроса координат и слушает
его изменения: отзыв доступа отменяет текущий поиск и убирает точку пользователя;
после выдачи доступа можно снова определить положение без перезагрузки страницы.
Если Permissions API не поддерживается или запрос его состояния завершается ошибкой,
состояние узнаём по результату нажатия. Кнопка при ошибке остаётся доступной для
повтора; на время поиска она отключена и помечена `aria-busy`.

Проверки: `e2e/interface.spec.ts` покрывает точность 20/50/51/150/280/800 м,
сохранение красного значка после закрытия сообщения и прежний поиск рядом.
`e2e/geolocation-control.spec.ts` проверяет выдачу и отзыв разрешения, отсутствие API,
таймаут, недоступность позиции, ожидание и восстановление точного положения.
Контраст цветов прицела на поверхности кнопки проверяет `src/styles/contrast.test.ts`.

Проверено 8 октября: `npm run check` прошёл (1 994 frontend-теста, 1 025 backend-тестов,
26 Python-тестов и 78 subtests, lint/typecheck и production-сборка).
Браузерные сценарии проверены в Chromium; мобильные снимки слабой, точной и
недоступной позиции просмотрены вручную. В рабочей копии уже был dev-сервер на
порту 3001, поэтому e2e запускались через локальную игнорируемую конфигурацию
`.audit/geolocation.playwright.config.ts`, чтобы не останавливать чужой процесс.
