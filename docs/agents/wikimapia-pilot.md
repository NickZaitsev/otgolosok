# Wikimapia: пилот на точках без рассказов

Пилот начат 2 октября 2026 года по поручению пользователя. Пользователь подтвердил, что тексты Wikimapia можно перерабатывать и использовать в сервисе; это решение зафиксировано в переписке, а не получено из доступной нам страницы условий. Фотографии и комментарии в пилот не входят.

## Методика

Из действующей production-базы одним запросом только для чтения получены публичные поля неархивных точек без **какой-либо** записи `place_texts`. Прямоугольник исследования: 55.68–55.82° N, 37.48–37.75° E; на момент выгрузки в нём 2308 подходящих точек.

Из них выбраны 40: 20 с `historic=memorial`, 10 с `tourism=artwork`, 10 остальных. При пересечении тегов приоритет у `artwork`. В каждой группе взяты первые записи в порядке SHA256 от строки `wikimapia-pilot-v1:<id>`; выборка зафиксирована до запросов к Wikimapia. Это небольшой стратифицированный пилот, его доли нельзя напрямую переносить на весь каталог или все города.

Для каждой точки `place.getnearest` запрашивает 50 соседей на русском языке. Фильтр предлагает кандидатов с расстоянием между центрами не более 150 м и совпадением хотя бы половины значимых слов имени, с грубым учётом окончаний; для первых трёх загружает `place.getbyid`. Фильтр служит только предварительному отбору: он не доказывает идентичность, игнорирует инициалы и не различает все виды объектов. Итоговая привязка и оценка полезности требуют ручного чтения названий, координат и описаний.

Отсутствие кандидата означает отсутствие совпадения **в этой выдаче и при этой методике**. Крупный объект может иметь далёкий центр; отдельная фигура может быть описана только в общей карточке ансамбля. Городской блок «Брестская крепость» нельзя подменять самой крепостью, надгробие нельзя подменять соседней могилой, биография человека не заменяет историю памятника.

## Доступ и надёжность

- Проверенные методы: `https://api.wikimapia.org/?function=place.getnearest` и `place.getbyid`; параметры `language=ru`, `format=json`. Для подробностей работают `data_blocks=main,location`; у `getnearest` блок `main` вызвал ошибку API 1901 внутри HTTP 200.
- Используется публичный тестовый ключ `example` с интервалом не менее 31 секунды. Работоспособность собственного ключа и пригодность для массового импорта этим не подтверждаются.
- Страницы документации и условий отвечали HTTP 429. Нельзя считать доступность главного сайта проверкой доступности API или наоборот.
- Клиент выполняет максимум три попытки при сетевом сбое, тайм-ауте, HTTP 429 и временных HTTP 5xx; учитывает `Retry-After` в пределах минуты и экспоненциальную задержку. Ошибки API в HTTP 200 сохраняются как ошибки, а не как отсутствие объекта.
- Ключ не сохраняется в артефактах и не выводится в ошибках. Полученные данные ограничены названием, описанием, координатами, категориями, идентификатором и канонической ссылкой; фотографии, комментарии, профили и IP пользователей отбрасываются.

## Воспроизведение

Скрипт `scripts/probe-wikimapia.mjs` принимает JSON `{places:[{id,name,lat,lon,tags}]}` с 1–50 уникальными точками и отдельный каталог вывода. Он не открывает и не меняет базу приложения, не вызывает модели и не публикует рассказы.

```bash
node scripts/probe-wikimapia.mjs backend/data/wikimapia-pilot/sample.json backend/data/wikimapia-pilot/responses --example
```

С собственным ключом задайте `WIKIMAPIA_API_KEY` через локальное окружение и уберите `--example`; ключ не передавайте аргументом командной строки. Для своего ключа интервал составляет не менее 3,1 секунды. Запускать один процесс; перед перезапуском с тестовым ключом выдерживать 31 секунду после последнего запроса.

Успешные ответы кешируются атомарной записью отдельных JSON. Повторный запуск использует кеш; ошибки не кешируются как успех. `report.json` обновляется после каждой точки, содержит признак полноты, неразобранных кандидатов и ошибки; незавершённый или частично ошибочный прогон не является готовым исследованием. При ошибках отдельных точек скрипт завершает остальные и возвращает ненулевой код; повреждение кеша или невозможность записи останавливают работу.

Локальная рабочая область: `backend/data/wikimapia-pilot/` (игнорируется Git). Проверенные результаты и сводка будут сохранены отдельно после завершения всех 40 точек.

## Результат

Исследование выполняется. До завершения ручной сверки численные выводы о покрытии и пригодности источника не зафиксированы.
