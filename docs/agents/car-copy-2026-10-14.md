# «Пройти на машине» для готовой прогулки

На экране готовой пешеходной прогулки перед началом добавлена кнопка «Пройти на машине». Она запрашивает автомобильный маршрут со всеми остановками в исходном порядке, подбирает общественные парковки и сохраняет новую поездку на устройстве. Общий бюджет — максимум 180 минут; при недоступной остановке или превышении бюджета копия не создаётся, причина показывается на исходном экране.

Ссылки на истории, ID остановок и их координаты сохраняются. Исходный опубликованный документ не изменяется; переведённый экран использует `sourceDocument` для сохранения русских исходных данных. Пешеходные переходы и подсказки сбрасываются, так как подъезд может отличаться. Прогресс пешеходной прогулки не переносится; поездка начинается с первой парковки. В аккаунт копия автоматически не записывается: она доступна в локальной библиотеке и может быть сохранена существующим редактором.

Проверки: полная команда `npm run check`, модульные проверки потери/подмены остановок, ошибки маршрутизатора, локального хранения и отмены, а также три сценария Chromium с автомобильным экраном и преобразованием готовой прогулки.

Пользователь запросил ревью Claude Opus 5.5. Вызов consultation-only `ask-advisor.sh` с `CLAUDE_ADVISOR_MODEL=claude-opus-5-5` завершился HTTP 400: `This model does not support assistant message prefill. The conversation must end with a user message.` Ревью этой моделью не состоялось; другая модель без согласия пользователя не использовалась. Независимое ревью остаётся незавершённым.
