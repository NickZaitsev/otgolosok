# Путь к Node с пробелом при полной проверке

9 октября 2026 `pnpm check`, запущенный через `fnm exec --using=24.20.0`, дважды завершился на тесте `backend/admin-make.test.mjs`: команда `make admin-create` пыталась выполнить `/Users/fenix007/Library/Application` вместо полного пути к Node. Отдельный запуск этого теста проходил. Полная проверка, включая 2093 теста Vitest, 1078 серверных тестов, проверки Python и сборку, прошла с `NODE=node fnm exec --using=24.20.0 pnpm check`.

Вероятная причина — `$(NODE)` в рецепте `admin-create` в `Makefile` запускается без кавычек, когда переменная содержит абсолютный путь с пробелом. Правильное исправление: экранировать исполняемый путь так же, как другие аргументы рецепта, и добавить тест с явным `NODE` в каталоге с пробелом. До исправления при запуске полной проверки в таком окружении можно задавать `NODE=node`.
