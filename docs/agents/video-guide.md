# Видеоинструкция по Отголоску

Композиция `OtgolosokGuide`: 1920×1080, 30 кадров/с, 79 секунд, без звуковой
дорожки. Семь шагов сопровождаются крупными русскими пояснениями, подсветкой
кнопок и анимированным курсором. Снимки экрана переключаются на результат
действия после нажатия; это монтаж последовательных состояний, а не непрерывная
запись экрана. Сайт не изменён для ролика.

## Откуда взяты кадры

Тест `e2e/video-guide.spec.ts` проходит реальный интерфейс текущей версии сайта.
API каталога и просмотра прогулки подменяются встроенным материалом
`public/data/routes/paveletskaya.json` через штатный адаптер `routeToWalkView`.
Сессия гостевая. Это воспроизводимая демонстрация интерфейса с локальными
данными, а не проверка production API. Карта загружается с OpenStreetMap;
авторство сохранено в кадрах и в монтаже. Геопозиция недоступна — в ролике
показано ручное переключение и это прямо объяснено.

Обычный запуск теста проверяет запуск/паузу аудио, чтение, выбор скорости и
переход к следующей истории. Для обновления снимков в PowerShell:

```powershell
$env:CAPTURE_VIDEO_GUIDE='1'
pnpm exec playwright test e2e/video-guide.spec.ts --workers=1
Remove-Item Env:CAPTURE_VIDEO_GUIDE
```

Съёмка дополнительно ждёт загрузки тайлов и завершения их появления: наличие
загруженного изображения ещё не означает, что Leaflet сделал его видимым.
Панель разработчика Next скрыта только на снимках. После изменения интерфейса
обновляйте PNG и `targets.json` вместе и визуально проверяйте подсветку.

## Монтаж и экспорт

Сценарий: `src/video/guide-timeline.ts`. Оформление и курсор:
`src/video/guide-step.tsx`. Вступление и финал: `src/video/otgolosok-guide.tsx`.

```bash
pnpm video:studio
pnpm video:render:guide
```

Экспорт и временные материалы находятся в исключённом из Git
`artifacts/video/`. Снимки в `video/assets/guide/` — исходные материалы ролика,
поэтому версионируются. Рендер не зависит от работающего сайта или доступности
тайлов: все нужные кадры локальные.

Рекомендации по Remotion: https://www.remotion.dev/docs/ai/skills.
