# Видеоинструкции по Отголоску

Две композиции на общем движке: `OtgolosokGuide` (как гулять по готовому
маршруту) и `OtgolosokCreateGuide` (своя прогулка по времени). Инструкция
описывается `GuideSpec`: шаги, цели нажатий, каталог озвучки и подпись в шапке.
Общий ролик — `GuideVideo` в `otgolosok-guide.tsx`.

Композиция `OtgolosokGuide`: 1920×1080, 30 кадров/с, около 100 секунд, голос
F5-TTS, тихий синтезированный фон и щелчки. Восемь шагов: у каждого есть
инструкция до нажатия и результат после него. Камера наезжает на цель, курсор
её нажимает, снимок плавно меняется на результат. Это монтаж последовательных
состояний, а не непрерывная запись экрана. Сайт для ролика не менялся.

## Кадры

Тест `e2e/video-guide.spec.ts` проходит реальный интерфейс: главная → «История» →
готовый маршрут → прогулка. API каталога и просмотра прогулки подменяются
встроенным `public/data/routes/paveletskaya.json` через `routeToWalkView`, сессия
гостевая. Снимки делаются в 1280×800 CSS-пикселей с `deviceScaleFactor: 2`:
камера увеличивает их до 1,8×, и снимки в 1× выглядели мыльными. Координаты
целей в `targets.json` хранятся в CSS-пикселях.

```powershell
$env:CAPTURE_VIDEO_GUIDE='1'
pnpm exec playwright test e2e/video-guide.spec.ts --workers=1
Remove-Item Env:CAPTURE_VIDEO_GUIDE
```

PNG не хранятся в Git (около 37 МБ): после клонирования снимите оба набора, иначе
`pnpm video:prepare` остановится с подсказкой. Проверка размеров снимков в
`guide-timeline.test.ts` пропускается, пока их нет.

Съёмка ждёт загрузки тайлов и завершения движения Leaflet. После изменения
интерфейса обновляйте PNG и `targets.json` вместе; тест `guide-timeline.test.ts`
проверяет, что каждая цель попадает в область камеры своего шага.

### Своя прогулка

`e2e/video-create-guide.spec.ts` снимает `video/assets/guide/create/` (ключи целей
`create/<снимок>`). Маршрут — кольцо вокруг Кремля: Манеж (Моховая, 1) →
Китайгородская стена → Большой Кремлёвский дворец → Боровицкие ворота, 3,7 км,
49 мин. Его построил планировщик `backend/walks.mjs` через Valhalla
(valhalla1.openstreetmap.de), истории и озвучка — опубликованные материалы
этих мест из локальной базы; всё сохранено в `e2e/fixtures/video-create-walk.json`
и `e2e/fixtures/audio/`. В центре опубликованных историй пока мало: кольцо с
памятником Ленину выходит за 60 минут. Кольцо должно занимать не меньше 75 %
выбранного времени, иначе панель покажет «Рядом нашлось мест только на …».
Перед щелчком по карте тест подводит Манеж под курсор, вычисляя экранную точку
по загруженной плитке OSM; перетаскивание завершается паузой, иначе инерция
Leaflet проносит карту мимо цели. В шаге «Идите по маршруту» геопозиция
подменяется точкой у второй остановки, затем нажимается «Дальше»: режим
переключения по умолчанию — «По кнопке». Цель нажатия меряется только после того,
как карта перестала двигаться, иначе рамка в ролике съезжает с кнопки или метки.

```powershell
$env:CAPTURE_VIDEO_GUIDE='1'
pnpm exec playwright test e2e/video-create-guide.spec.ts --workers=1
Remove-Item Env:CAPTURE_VIDEO_GUIDE
```

## Озвучка

Текст — `video/src/guide-narration.json` и `video/src/create-guide-narration.json`
(`<шаг>-do`, `<шаг>-done`, `intro`, `outro`); список инструкций — `GUIDE_VOICES`
в `video/scripts/build-guide-voice.mjs`. `pnpm video:voice` отправляет изменённые фрагменты в just-tts
(`POST /v1/jobs`, профиль `f5-ru-v1`). Скрипт проверяет SHA-256, пишет MP3 и
`manifest.json` с длительностью в `video/assets/guide/voice/` (вторая инструкция —
`video/assets/guide/create/voice/`) и подтверждает
приём. Ключ фрагмента учитывает текст и контрольные суммы профиля. Повторный
запуск пропускает готовые фрагменты. Длительности шагов считаются по manifest,
поэтому нажатие совпадает с концом инструкции.

F5 плохо озвучивает очень короткие фразы: «Выберите следующую историю.» вышла
на 20 дБ тише остальных и неразборчивой. После генерации проверяйте громкость:

```bash
ffmpeg -i video/assets/guide/voice/next-do.mp3 -af volumedetect -f null -
```

Нормальный фрагмент: mean около −17 дБ, max около −2 дБ.

## Монтаж и экспорт

Хронометраж — `guide-timeline.ts`, камера — `guide-camera.ts`, окно браузера и
курсор — `guide-browser.tsx`, шаг — `guide-step.tsx`, вступление и финал —
`otgolosok-guide.tsx`. Шрифты Manrope и Cormorant Garamond берутся из
`@fontsource` и копируются в public при подготовке; для рендера сеть не нужна.
Фон и щелчок синтезирует `video/scripts/build-guide-audio.mjs` при `video:prepare`.

```bash
pnpm video:studio
pnpm video:render:guide
pnpm video:render:create-guide
```

Рендер использует PNG-кадры, CRF 16, x264 `slow` и bt709: так текст интерфейса
остаётся без артефактов JPEG. Файл — `artifacts/video/otgolosok-guide.mp4`.
Бандл Remotion копирует public во временный каталог (около 50 МБ). При почти
заполненном диске C: рендер падает с `ENOSPC` ещё на копировании.

Рекомендации Remotion: https://www.remotion.dev/docs/ai/skills.
