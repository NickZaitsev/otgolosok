# Переозвучка 198 F5-рассказов через ElevenLabs v4

Статус: завершено.

8 октября 2026 года пользователь прямо поручил переозвучить все 198 F5-текстов из прежней выборки внутри Садового кольца и до 100 м снаружи через ElevenLabs v4. Используются текущие одобренные рассказы после [редактуры адресных справок](garden-ring-address-cleanup-2026-10-08.md). «Приют Третьякова» уже переозвучен отдельно и не входит в эту партию.

## Запуск

Перед постановкой в очередь сверены все 198 идентификаторов и хешей текстов с предыдущей публичной проверкой. Подтверждены отсутствие новых черновиков, исследований и активных аудиозаданий, неизменность карточных адресов и координат, наличие прежних F5-файлов. Свободно около 9,91 ГБ.

Параметры всех новых записей: `provider: elevenlabs`, `model: eleven_v4`, голос «Отголосок2», логический ID `9ivxhQ6xIsHd6R3Xc635`. Исторический идентификатор профиля очереди `elevenlabs-v3` сохраняется в коде и базе; фактическая модель задаётся отдельно и проверена как v4.

Для каждой точки создан отдельный детерминированный `revoiceRequestId`: это явное намерение новой записи, исключающее переиспользование старой модели и повторную оплату при возобновлении операции. Повторный запуск сверяет намерение, текст, модель, голос и текущий выбор профиля; чужая активная озвучка или редакция считаются конфликтом.

Все 198 заданий поставлены в очередь, постановка завершена `2026-10-08T15:37:37.692Z`. Приложение озвучивает их последовательно. Предыдущие MP3 остаются доступны до готовности замены и сохраняются после неё; тексты и карточные поля не редактируются.

Резервный снимок только этой партии с текстами и прежними аудио сохранён в `/data/ops-backups/garden-ring-eleven-v4-2026-10-08/before.json`, около 1 МБ. Полные копии SQLite по точкам не создавались. Результат постановки сохраняется после каждого задания атомарной заменой `publication.json`; локальные снимки и вспомогательные скрипты находятся в игнорируемой папке `backend/data/garden-ring-eleven-v4-2026-10-08/`.

## Проверки

Мониторинг сверяет хеш исходника, полный рассказ, идентификатор текста, карточные поля и доступность прежнего MP3 для всей партии. Готовые задания дополнительно проверяются по фактическому артефакту: ElevenLabs, v4, нужный голос, наличие и размер файла, совпадение с выбранной публичной записью.

Публичная проверка читает каждую карточку и скачивает новый и прежний MP3 через `curl --http2` с ограниченными повторами сетевых ошибок. Проверяются точные текст и идентификатор, адрес и координаты, минимум 100 слов без отдельно стоящей пунктуации, SHA-256, размер и длительность MP3 через ffprobe. Финальная проверка всей партии проведена после окончания очереди.

Во время генерации временно возникли ошибки текстового провайдера `PROVIDER_UNAVAILABLE` (HTTP 5xx) на этапе подготовки аудиотегов и `TTS_FAILED`. Повторы существующей очереди восстановили обработку. Новые задания вместо существующих не создавались, модель и тексты не менялись.

При повторном общем HTTP 5xx обнаружен риск: speech-worker расходует попытки отдельных заданий, поскольку общей паузы провайдера у него нет. Незавершённым заданиям только этой партии дважды отложен `next_attempt_at` на две минуты при двух отдельных общих сбоях, без изменения счётчиков попыток, текста, модели и идентификаторов заданий; сохранён отдельный аудит каждого переноса. Постоянное исправление: добавить общую ограниченную паузу для `PROVIDER_OUTAGE_CODES` по аналогии с content-worker, с тестами сохранения бюджета попыток и возобновления после восстановления. Код приложения в этой операции не менялся.

Бесплатная свежая проверка трёх аккаунтов подтвердила голос «Отголосок2 (ru)»: основной ID `9ivxhQ6xIsHd6R3Xc635`, резервные копии `JVYtLnrrrMG4dcGbtdAw` и `8Hp7MfQf2HGTKtrxXvVj`. В артефактах записан логический ID основного голоса. Проверка выполнена с `fetchImpl` из npm undici: глобальный fetch в отдельном процессе воспроизводит уже описанный [дефект заголовков и brotli](ostozhenka-povarskaya-release-2026-10-08.md), код работающего worker не менялся. Ключи API в результатах отсутствуют.

Каждая новая публичная запись имеет ElevenLabs v4 и логический голос «Отголосок2». Тексты, их идентификаторы, карточные адреса и координаты сохранены.

На `2026-10-08T18:01:41Z` финальная свежая публичная проверка всей партии прошла без ошибок: 198 карточек и 396 различных MP3, включая все прежние F5-файлы. Все файлы заново скачаны после окончания генерации, проверены по SHA-256, размеру и длительности через ffprobe. Голос основного и двух резервных аккаунтов дополнительно подтверждён свежими запросами к ElevenLabs.
