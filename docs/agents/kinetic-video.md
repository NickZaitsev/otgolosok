# Кинетический ролик без Remotion

Вертикальный рекламный ролик 1080×1920, 30 кадров/с, 24 секунды. Шесть сцен:
«Прислушайтесь к городу» (эхо-копии строки и круги от точки) → «У каждого
переулка/двора/фасада/дома — своя история» (слот-машина слов, фасад в арке,
вращающийся бейдж) → маршрут на наклонённой в 3D карте с подписями остановок и
счётчиками → телефон с экраном прослушивания и эквалайзер по реальной озвучке →
три обещания жёсткими склейками на ударах → знак «Отголосок.» с эхо-кругами.

## Как устроено

- `video/kinetic/timeline.mjs` — хронометраж сцен, фрагмент голоса и чистая
  математика (кривые, пружина, полосы для clip-path, ломаная маршрута). Общий
  для страницы и Node; тест — `src/video/kinetic-timeline.test.ts`.
- `video/kinetic/scene.mjs` — сцена на обычном DOM/SVG. Всё движение задаётся
  только в `seek(t)`: никаких CSS-transition, `@keyframes`, таймеров и
  `Math.random`, иначе кадры перестанут быть воспроизводимыми.
- `scripts/render-kinetic-video.mjs` — локальный HTTP-сервер (страница, шрифты
  `@fontsource`, подготовленные материалы), Playwright Chromium снимает PNG
  каждого кадра и передаёт их в stdin FFmpeg. Любая ошибка страницы, 4xx/5xx
  ресурса или незагруженный шрифт останавливают рендер.

## Данные

Путь маршрута и метки берутся из `public/data/maps/paveletskaya.svg`
(`#walking-path`, `g[data-step]`), подписи — `story.opening` из
`public/data/routes/paveletskaya.json` (сначала `notes`, потом `pois`), подложка
карты — та же `stripRouteLayer`, что у `OtgolosokMotion`. Если число меток и
историй разойдётся, рендер падает. Экран телефона — центральная полоса снимка
`video/assets/guide/listen.png` (2560×1600); при замене снимка проверьте
координаты кнопки воспроизведения в `scene.mjs`.

## Звук

Музыка — `motionBedWav(musicScore())`: склейки стоят на долях 0,5 с (120 уд/мин),
приглушение под сценой прослушивания. Голос — первые 3,6 с
`kozhevniki-*.mp3` (до первой паузы), уровни для эквалайзера считаются из того
же фрагмента. У `alimiter` отключён `level`: по умолчанию он поднимает сигнал
обратно к 0 дБ. Контрольная громкость: mean −21,6 дБ, max −5,5 дБ.

## Команды и проверка

```bash
pnpm video:render:kinetic                                 # около 2,5 мин, ~16 МБ
pnpm video:preview:kinetic                                # живой просмотр, ?preview&t=7
node scripts/render-kinetic-video.mjs --stills 1.5,9.5,22 # PNG в artifacts/video/kinetic-stills/
```

Проверено 28 сентября 2026: полный рендер 720 кадров за 133 с на Windows,
h264 + AAC, ровно 24,0 с. Отдельные кадры каждой сцены просмотрены глазами.
