# Генерация текстов в production, 28 сентября 2026 года

Проверка только на чтение в 15:32 UTC. Работающий контейнер `otgolosok-generator-generator-1` использует `OPENAI_BASE_URL=https://airouter.softmg.tech/v1`; ключ задан, а `STORY_MODEL` и `WRITER_MODEL` не заданы, поэтому действуют значения по умолчанию из `backend/provider.mjs`. Адрес `https://router.airouter.softmg.tech/dashboard/analytics` относится к другому приложению: главная страница `airouter.softmg.tech` называется «AI Router - OpenAI-Compatible API Gateway», а `router.airouter.softmg.tech` — «OmniRoute — AI Gateway for Multi-Provider LLMs». Поэтому панель OmniRoute не показывает запросы, отправленные на первый хост. Совпадение IP-адресов не делает их одним сервисом.

В базе генератора было 377 заданий `queued`, одно `working` и одно `retry_wait`. `CONTENT_WORKER_CONCURRENCY` не задан; `startContentWorker` по умолчанию выполняет одно текстовое задание за раз. За текущие сутки 176 попыток закончились `ready` (средняя длительность 146 секунд), 126 — `review_required` (144 секунды), 40 — `retry_wait` (98 секунд). Среди последних повторов встречался `TIMEOUT`. Эти длительности включают весь цикл задания, поэтому по ним нельзя отдельно оценить задержку Airouter. При текущей очереди последовательная обработка сама по себе даёт много часов ожидания.

Для точного разбора задержки нужны метрики запросов на действующем `airouter.softmg.tech` или измерения отдельных этапов генератора. Переключать `OPENAI_BASE_URL` на `router.airouter.softmg.tech` без проверки ключа, моделей, `web_search` и маршрута `/responses` нельзя: это отдельный сервис. Ускорение очереди требует оценки допустимой параллельности и лимитов провайдера; текущее значение равно одному заданию.
