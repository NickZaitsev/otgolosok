`RTK.md` отсутствует; ToolSearch/Ruflo в инструментах сессии нет. Делегирования не было. Прочитано руководство установленного Next.js о клиентской границе. Работа выполнялась поверх коммита `30bda843bdbe305fb803bea52271e8183293951c`; сторонние правки материалов прогулки не затрагивались.

## Поведение и ограничения

- Переключатель «Еда» находится среди MapShell-кнопок, имеет FoodGlyph, `aria-pressed`, цель 44×44 и фон активного состояния. Настройка `otgolosok:around:food:v1` по умолчанию выключена; чтение и запись защищены try/catch. Недоступность хранилища не мешает переключению в памяти. Доступ к localStorage в подсказке геопозиции на этом же экране также защищён.
- Манифест проверяется на обычном экране, чтобы скрыть кнопку при 503. Ячейки через `foodCellStore.loadArea` загружаются только при включении и масштабе ≥15. При меньшем масштабе notices показывают «Приблизьте карту, чтобы увидеть заведения». Сетевые ошибки/500/429 используют готовые ограниченные повторы; после ошибки доступен ручной повтор. 503 не повторяется автоматически и скрывает функцию.
- Отбираются только места внутри `required`: это видимая область с запасом полшага масштаба (примерно 1,41 размера по каждой оси). Большой `buffered` историй для заведений не используется. Если в области более **300** заведений, рисуются ближайшие к центру **300**, равные расстояния разрешаются по id. Полная ячейка остаётся в общем кеше, но все её 1 600 мест не превращаются в DOM-метки.
- Food-метки используют готовые `MarkerKind food` и `foodMarkerSvg`; отдельная pane с z-index 590 ниже story-pane 600 независимо от координаты и выбранности. Кластеризация с историями уже запрещена кодом фазы 4. Экранные id заведений имеют префикс `food:`, поэтому история и заведение с одним OSM id не конфликтуют.
- `FoodCard` экспортирована из `food-list.tsx` и используется и прогулкой, и `FoodSheet` в around-sheets. На карте заголовок и закрытие находятся в фиксированном header Sheet, тело прокручивается; кнопки «Назад к списку» нет. Расстояние «≈ N м от вас» вычисляется по прямой только при известной позиции. Часы, оговорка, исходное правило, безопасные ссылки, атрибуция и дата остаются общими. Часы обновляются на границе минуты; `createFoodHoursCache` живёт весь срок экрана. Ссылка «Сайт» исправлена до ширины не менее 44 px.
- Выбор истории, заведения или дома закрывает предыдущую карточку. В режиме создания прогулки переключателя и загрузки food API нет.
